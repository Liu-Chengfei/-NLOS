# 核验流程（verify_slam 执行）

## 一、核验顺序

1. **八字段自检**：按 `skills/落实报告书写/SKILL.md` 提交前自检清单逐项核对
2. **磁盘锚点核验**：按 `rules/状态只认磁盘.md` 核验清单核对
3. **verify_slam 执行**：运行综合核验脚本
4. **判据逐项对照**：执行判据条款对应的校验脚本/断言

## 二、verify_slam 脚本

综合核验脚本 `verify_slam.py`（或等效脚本）必须覆盖：
- 落实报告格式八字段完整性
- 治理载体文件:行号引用有效性
- 条款原文与落实字段逐句映射
- 证据路径真实存在性
- 五铁律合规性

运行命令：`python verify_slim.py`（等效脚本）
预期：所有断言通过，无缺失字段、无虚假路径、无空话

## 三、通过/不通过判定

| 结果 | 处置 |
|------|------|
| **PASS** | 该条落实通过，进入下一条 |
| **FAIL** | 标注 ❌ → 停工修复 → 重写该条落实报告 → 复验通过后方可继续 |

## 四、循环修改纪律

若审查中发现"违反→改→重映射→不违反"轨迹：
1. 在"审查:"字段写完整轨迹
2. 在 decision log 记录修复原因
3. 重跑 verify_slam 确认通过
