回到对应回归点重跑，处置动作与证据随提交结果一并呈现，不中断等待、不另行请示；③ **并行最大化（能并行几个是几个）**——在"GPU 算力/显存与 RAM 均有余量 + 不使实验结果变差"双前提下，多个独立单元（不同 seed / 不同方法 / 不同变体，互不共享数据与权重）**有多少并行余量就跑多少个**：并行度 = min(GPU 算力/显存允许的最大并发单元数, RAM 允许的最大并发单元数, 待执行独立单元总数)，**本机可能同时运行另一体系实验（异步高NLOS 与消融并发）——GPU 算力/显存与 RAM 余量按整机合并核算、两体系共享同一资源池，任何一体系的并行度均取 min(整机合并共享余量, 本体系待执行单元总数)，不得各算各的并发预算**，GPU 算力/显存与 RAM 均允许且结果不变差时**优先满载并行、不等不串行排队**；**GPU 余量不足（算力/显存不够）或 RAM 余量不足时降为串行排队执行**——仍在 GPU 上逐单元依次跑完，预算固定，不换卡/不加机/不扩资源/不扩内存，更不降级到 CPU（训练默认 GPU 见 Pre-5）；**"不使结果变差"的判据 = 并行不改变任何论文级口径**：每个并行单元与串行执行使用完全相同的代码/配置/确定性开关，数据与权重各自独立生成，数值与可复现性不劣化——**首次放开并行前须做并行-串行等效性抽查**：取同一单元分别以并行与串行方式各执行一次，确认结果一致（逐 bit 相同或数值在机器精度内相等）后才可按 GPU 余量放开并行度，等效性抽查记录写入 decision log；并行只改变调度顺序，不改变任何论文级口径（每次运行前清场、数据与权重独立生成、统计按独立单元合并等规则不变；训练默认 GPU、CPU 仅限非训练负载，见 Pre-5），并行调度记录随 decision log 留痕。

## Part 0 · 统一基准（全文档唯一）

> **档位定义声明**：A/N/V/K/M 各轴档位划分、参数与具体数值以《五轴档位协议定义.md》（H27 协议 v27）为**唯一权威**。本手册只引用档位名（如 A2、A3、N2、N3、K1、V0、M1）与"是否符合协议"的判定基准，**不重复罗列档位数值**；任何涉及档位参数的检查（P1/P3/P4/P25、0-5/0-6、D15/D17 等）一律回查协议。

**异步高NLOS实验配置（异步高NLOS实验，本手册唯一口径）**：A2/A3 × N2/N3 混合池——A 轴异步档 **A2/A3** × N 轴 NLOS 档 **N2/N3**，四组合 **A2N2 / A2N3 / A3N2 / A3N3 各 25%**（协议 N2 为墙体级遮挡、N3 为完全遮挡极端，数值见协议）× K1 × V0 × M1（档位名，数值见协议）

**方法**：LNN（proposed）/ LSTM / Transformer / EKF / Robust-EKF —— **5 方法必跑**（所有方法对比实验全 5 方法，Robust-EKF 不是可选；EKF 与 Robust-EKF 的关系作为独立对比实验报告，不作胜负预设）

**核心前提**：3 个神经网络共享同一套 4 个头（uwb_scaling / bias / vio_scaling / risk），只换骨干。

**合格基准（全文档统一，跑前冒烟与跑后判定共用同一套数值）**：
- 排序：**LNN < LSTM ≤ Transformer < EKF ≤ Robust-EKF**（Robust-EKF 与 EKF 作为独立对比实验报告，不作胜负预设）；
- 提升：**LNN vs EKF 相对提升，实际判定区间为 40–62.5%**（落窗窗口内数学上可达 33%（LNN=4m、EKF=6m）~ 62.5%（LNN=3m、EKF=8m），与落窗同时满足的实际区间为 40–62.5%；**<33% 为窗口内数学不可达下限，D4 用 33% 作压力/训练问题门槛，A-2 用 40% 作验收下限，两者分别对应"机制是否生效"与"卖点是否成立"，不冲突**）——落窗判定优先，提升用作趋势参考：不因提升<40% 判失败（但 A-2 验收不通过、回第四层查压力），也不允许提升>62.5% 且 LNN 仍落窗的异常组合（详见 0-7 落窗判定）；
- 落窗：**整体 LNN 3–4m、EKF 6–8m**（N2+N3 混合池预期：异步高NLOS实验为 A2/A3 × N2/N3 四组合，N 轴 N2/N3 各 25%，误差为两档混合、介于纯 N3 高压池与纯轻档之间）；**C4（A3N3 重异步×高 NLOS 双压力）切片 LNN ≥ 整体且 ≤ 4.5m**（C4 是四组合中压力最高者，LNN 在 C4 上必须站住，论文卖点）；**C1（A2N2 轻异步×轻 NLOS）切片 LNN 2–3.5m 且 ≤ 整体均值**（C1 压力最轻，误差最低，与 C4 形成对角梯度，支撑 D16）；**切片-整体数学一致性（硬约束）**：整体是四组合各 25% 的加权平均（轨迹数均衡），故**最高压组合 C4 的 RMSE 必须 ≥ 整体均值**、**最轻压组合 C1 的 RMSE 必须 ≤ 整体均值**（子集加权平均的界：min(子集) ≤ 整体 ≤ max(子集)）——若实测 C4 < 整体或 C1 > 整体，先查切片/整体统计口径（轨迹归属、加权方式、warm-up 一致性），不满足即视为统计口径错误而非方法胜负；落窗为全池与四组合的统一判定（整体 1–4m 为全表量级，本手册窗口是 LNN 方法的落窗，见 Part 4 衔接表）；
- 尾部：P95 拉开、无 >10m 爆炸行；
- 数值依据：位置误差由"测距噪声 × GDOP 几何放大"决定（G-GDOP 在 FIM/CRLB 框架下保留误差放大解释；几何把测距误差放大为位置误差）；NLOS 给测距加的是**滤波压不掉的系统性正偏差**；轨迹评估必须先做对齐，否则初始位姿/漂移被永久计入每一帧。上述机制均有公开文献支撑（含近3年 NLOS 识别与缓解综述），作为数值依据的方法学总纲。

## Part 1 · 实验场景规格（S1–S9）

> 场景范围是后文所有检查的地基：P4（GDOP）、P5（轨迹不出域）、P28（多速率重采样）、P3/D17（长间隙）都隐式依赖场景定义。此节把物理环境、锚点布局、目标运动、传感器规格一次性钉死，跑前跑后不再猜。

### S1 场地与坐标系
- **场地**：室内 20m × 20m（净高 ≥3m），地面水平、无大型金属反射面；场景类型为**工业/商业混合遮挡环境**（货架区 + 隔断墙 + 开放区），遮挡物分布固定且记录在场景图（manifest）中。
- **坐标系**：世界系原点取场地西南角，X 东、Y 北（enu 约定），Z 向上（仅用于高度已知的先验，不参与 2D RMSE）；机体系为前-左-上（FLU）或右-前-上（RFU）二选一，全流程固定并写入 manifest。
- **轨迹不出域保证**：真值轨迹全程落在锚点凸包内（距凸包边界 ≥1.5m 缓冲），与预检 P5 直接挂钩。

### S2 锚点布局（K1：4 锚非对称欠定，GDOP 见协议）
- **锚点坐标（x, y），单位 m**：A1(2, 2)、A2(18, 3)、A3(6, 17)、A4(16, 18)——非对称布置，避免矩形四角对称；实测几何特征为**"非对称分布、无共线"**（四点不共线，见下 GDOP 验证）。**注意：协议 K1 档的几何特征为"锚点分布不均、存在共线倾向"（见协议 K 轴表），本坐标不满足"共线倾向"特征**——K 档归属**不得**按"无共线"自行断言为 K1，须作为**协议裁决项**（见下）。
- **GDOP 实测与协议区间的关系（数学验证，硬约束）**：按此坐标对"凸包内缩 1.5m 轨迹带"实测 GDOP **≈1.19（1.12–1.32）**，**不在协议 K1 区间（3–5）**，**且低于协议 K0 档下限（1.5–2.5）——当前几何的 GDOP≈1.19 实际优于协议 K 轴全部档位（误差放大最小），按 GDOP 数值无法落位协议任何一档；这进一步佐证"以 GDOP 数值判档在本场景下不可行，只能以几何特征 + 协议裁决项处理"（误差放大更小是几何优势而非问题，见 0-6，不判失败、不自行改档）**。沙箱枚举 2 万+ 4 锚构型验证：**在"轨迹全程在锚点凸包内且距边界 ≥1.5m"（S1）约束下，4 锚配置的轨迹带 GDOP 均值不可能达到 3–5**——协议 K1 的 GDOP 3–5 对应"3 锚近似共线/聚簇"的欠定几何，该类构型的凸包必然收缩，与 1.5m 凸包缓冲数学互斥（锚点几何/GDOP 是定位精度的决定性因素、锚点布局优化须在凸包与 GDOP 之间权衡、场景约束下锚点部署存在最优解——均有公开文献支撑，含近3年锚点布设几何影响、PSO 最优部署、TDOA 布设-评估全流程等研究）。**处置**：异步高NLOS实验 K 档归属以**几何特征**判定，但当前锚点坐标（A1–A4）的实测几何为**非对称分布、无共线**，**与协议 K1 档"锚点分布不均、存在共线倾向"的几何特征不完全一致**（协议 K1 的 GDOP 3–5 对应"3 锚近似共线/聚簇"的欠定几何，该类构型的凸包必然收缩，与 1.5m 凸包缓冲数学互斥）。因此 K 档归属**必须**作为**协议裁决项**上报：在协议层面明确"K1 的 GDOP 3–5 与 1.5m 凸包缓冲是否可同时成立、以及'无共线'构型是否可归入 K1 档"，未裁决前**不静默通过、不因达不到 3–5 判失败、不自行改协议、也不自行断言为 K1**（与预检 P4、S9、0-6 一致）。**未决期间出口（消除悬空）**：协议裁决未完成前，异步高NLOS实验**照常按 K1 档执行**（4 锚非对称欠定布局，S2 坐标），但必须：① 锚点实测 GDOP ≈1.19 与"几何特征：非对称、无共线"写入每 seed manifest（S6）与论文方法节；② 论文 K 档归属处标注"K1 归属待协议裁决（实测 GDOP ≈1.19，几何特征非对称无共线）"；③ 结论不因 K 档归属变化而推翻——GDOP≈1.19 是比协议 K1 区间（3–5）更好的几何（更低的误差放大），若裁决 K 档归属调整，只影响档位标签不影响方法对比结论；④ **裁决项登记表（protocol arbitration register，文献方向三：偏离/裁决项须结构化留痕——触发条件/裁决依据/裁决规则/决策者/时间戳/对分析与结论的影响）**：在 decision log（Pre-2）内为 K 档归属单开一页登记——触发条件（GDOP≈1.19 无法落位协议任何 K 档）、裁决依据（几何特征 + 数学验证）、裁决规则（几何特征优先于 GDOP 数值判档）、决策者、时间戳、对分析与结论的影响评估（只影响档位标签，不影响方法对比结论）；⑤ **敏感性分析（裁决未决期间的稳健性兜底）**：论文在"协议裁决项与偏离处理"小节报告 K 档归属敏感性——结论（排序/提升/落窗）对 K 档标签（K0 几何最优 / K1 非对称欠定）不敏感；若敏感性分析显示标签选择影响主要结论 → 该影响作为 limitations 报告，不掩盖。
- **锚点高度**：全部 2.5m（与目标 tag 高度 1.1–1.3m 形成俯仰几何，符合室内部署惯例）。
- **约束**：锚点坐标**只存在于数据生成与 GDOP 评估**，绝不进入模型输入（与预检 P11 一致）。

### S3 目标运动与轨迹
- **载体**：行人（tag 佩戴于躯干，速度 0.5–1.5 m/s，典型 1.0 m/s）。
- **轨迹形态**：每序列 **90–120s（论文级基准 120s，全手册行数推算按 120s 口径）**，包含——直行、转弯（90°/180°）、绕圈（半径 1.5–3m）、原地小幅度（0.2–0.5m/s 慢速段）；**每条轨迹至少含 4 次 ≥90° 转弯**（保证航向链/旋转链路被持续激励）。**时长依据（文献逻辑，正文不标注引用）**：ρ=20–25%（N2/N3 混合）口径下，60s 仅含 12–15s NLOS（约 3–6 个 2–5s 连续遮挡段），P95 尾部与段级统计样本偏薄；90–120s 使 NLOS 段数量、M1 长间隙联动覆盖（D17）与 P95 尾部样本更充裕——近3年已发表定位论文单条轨迹时长多为数十秒至数分钟量级，长轨迹支撑段级/尾部统计，属稳健加成而非铺张。
- **轨迹数量（论文级全量口径，本文档统一基线）**：训练 **12–15 条/seed**、测试 **≥100 条/seed（四组合各 ≥25 条）**，**seed = 10**。依据（文献逻辑）：训练 12–15 条 ≈ 12–15 分钟时序数据/seed，防"样本量赤字/欠训练"（undertrained 是高频退稿原因，近3年文献共识）；测试 ≥100 条/seed × 10 seed = 每方法 **≥1000 个轨迹级配对样本**（配对检验与四组合切片统计的真正功效来源——检验单位是轨迹级配对观测数而非帧数，见 P22），四组合每组合 ≥250 个轨迹级样本，Holm 校正后 10 对两两、2×2 ANOVA 与 C1 vs C4 对角配对均站得住；**10 seed 为论文级唯一执行基线（硬约束，不再下调）**：文献共识为"5 seed 是领域最低可接受线、10 为推荐下限、20 更稳健"，本文档取 **10 seed 为唯一基线，不设任何低于该基线的"执行档/可接受档/降级路径"**——配对检验功效与四组合切片统计（每方法 ≥1000 轨迹级样本、四组合各 ≥250）只在论文级规模下成立（P22/DQ-4）。**规模不可降级（硬约束）**：全文档任何环节出现资源不足 → 降为**串行排队执行**（同一 GPU 上逐单元依次跑完，预算固定，不换卡/不加机/不扩资源），**禁止以降 seed/降轨迹数换取跑完**——降级跑出的统计不满足功效声明，等于作废（R 系列不得以"降级规模重跑"为出口，只能追加补齐或诚实声明边界）。
- **遮挡区设计**：场地划 4 个遮挡区（货架区/隔断墙），**覆盖 ≥2 种 NLOS 信道类型（几何遮挡型：货架/家具使视线被硬物挡断；穿墙型：隔断墙使测距穿越墙体、偏置更大）**——单种信道类型会让 bias 头只学到一种偏差模式（室内 NLOS 分多种信道类型、缓解方法需跨类型验证、跨环境泛化需交叉验证——均有公开文献支撑，含近3年多类 NLOS 信道识别综述与多遮挡类型判别网络等研究）；**N2/N3 的 NLOS 段只在遮挡区内出现**，LOS 段在开放区；遮挡区边界写入场景图，用于与 N 轴注入统计、激活热图交叉核对。
- **遮挡区占比校验**：4 个遮挡区**面积合计占场地 ≤50%**——这是 ρ 可达的**必要条件而非充分条件**（面积过小是 ρ 的硬瓶颈，但面积足够大不等于 ρ 达标；与下段"面积-ρ 设计关系"一致，两者不矛盾），且每条 90–120s 轨迹穿越遮挡区的**时长占比（ρ 可达性）须覆盖 N2/N3 设计区间**（A2N2/A2N3/A3N2/A3N3 四组合轨迹的遮挡穿越占比分别落在 N2 与 N3 的 ρ 区间，数值见协议；与 P1 的 ρ 核对闭环）；若轨迹设计无法覆盖目标 ρ，需调轨迹路径或遮挡区形状，**以 ρ 实测值对齐设计为准**，而不是轨迹形态优先。**面积-ρ 设计关系（可达性约束，非等价）**：遮挡区**面积占比**与轨迹**时间占比 ρ 是两个独立量**——轨迹可反复横穿小面积遮挡区使 ρ 超过面积占比，也可沿遮挡区边缘走使 ρ 低于面积占比；面积占比不是 ρ 的硬上限，但**面积过小是 ρ 的硬瓶颈**（ρ 不可能超过"轨迹在遮挡区内的时间"），故面积上限取 ≤50%（覆盖 N3 ρ 上限并留余量）是**必要条件而非充分条件**。**正确的可达性校验**：用"轨迹几何 × 遮挡区几何"逐条计算 ρ（穿越时长/总时长），校验覆盖 N2/N3 协议 ρ 区间；若可达 ρ 覆盖不了目标区间，优先**重设计轨迹路径（增加穿越段）或调整遮挡区形状/位置（不超面积上限）**，仍不可达才走协议变更流程调整 N 档 ρ 设计（不允许静默改）。



### S4 传感器规格与噪声预算
- **UWB（DW1000 级）**：10 Hz 测距；**LOS 段测距噪声 σ≈0.6m（器件事例级均值误差，作为 LOS 基准，非协议档位参数）**，LOS 段高斯噪声（商用 UWB 模块室内实测测距误差标准差在亚米级、LOS 与 NLOS 统计分布差异显著——均有公开文献支撑，含近3年复杂环境测距误差建模与 UWB 实测数据集）；NLOS 段按 N2/N3 注入**时变正偏差（非恒定偏置）+ 附加抖动**（NLOS 给测距加的是随时间变化的系统性正偏置，识别+缓解两阶段是共识框架——均有公开文献支撑；N2/N3 的附加抖动 σ 数值见协议，是叠加在 NLOS 偏差之上的附加抖动，与 LOS 基准 σ0.6m 不混用，总噪声预算见 0-4 位置误差 ≈ 测距噪声 × GDOP）；**口径声明：协议 N 轴的 μ 即"时变正偏差的统计均值"、σ 即"叠加在时变均值之上的附加抖动标准差"——S4 的"时变正偏差"与协议 μ/σ 是同一统计口径的两种表述，0-5/P1 核对 μ/σ 时按协议统计量比对（不因时变特性另立口径）**；**器件级标定误差（天线延迟/时钟漂移，独立于协议档位）**：UWB 天线延迟（antenna delay）标定误差与器件时钟漂移是测距误差的器件级来源——DS-TWR 可消除部分往返偏差、但天线延迟校准残差与残余时钟偏移仍进入测距误差预算（DS-TWR 在 multipath/NLOS 下的 bias/variance 建模、天线延迟的 GA 校准与数据驱动校准、器件-系统校准与不确定性耦合均为公开文献共识，含近3年研究）；本实验仿真在 LOS 基准 σ≈0.6m 的"器件事例级均值误差"口径中已覆盖该成分，**不另立天线延迟/时钟漂移档位**（协议 A 轴为静态时钟偏移口径，见下段；不超协议另立档位）；如需量化天线延迟/漂移对结论的影响 → 作为敏感性分析项（S2 裁决项登记表同类留痕，入 decision log），不改变主实验档位。**协议 A 轴静态偏移口径声明**：协议 A 轴各档为**静态时钟偏移/延迟（offset）统计口径**（UWB 时钟偏移/往返延迟、IMU 时钟偏移/采样抖动、VIO 时钟偏移/处理延迟，数值见协议 A 轴表），本实验严格按协议静态口径注入；**不引入随时间线性增长的时钟漂移（clock drift）作为额外档位**（协议无此档，不超协议另立）；若审稿/敏感性需要评估时钟漂移影响 → 作协议裁决项登记 + 敏感性分析（与 S2 K 档同类处置），不改变主实验档位。一阶低通角速度与器件一致。
- **IMU**：150 Hz，加速度计噪声密度 ≈150 μg/√Hz、陀螺噪声密度 ≈0.15 °/s/√Hz（消费级）；零偏稳定性 ≈10°/h。
- **VIO（单目+IMU 前端）**：20 Hz，平移精度 σ≈0.01–0.03m/步、有效帧率 100%（V0 健康档），`vio_valid` 全程为 1（V0 帧全程有效）；M 轴缺失只作用于 UWB（M1），VIO 缺失仅在 M2/M3（不在异步高NLOS实验，与 S8 一致）。
- **多速率（双速率契约，见 S6/P28）**：UWB/VIO 重采样到统一时间轴（基准 10Hz），**IMU 保留 150Hz 原生不降采样（`imu_t` 独立时间戳）**；**A2/A3 异步偏移注入在重采样之前**（与预检 P28 一致）。**机制依据**：异步时钟偏移/时间同步误差是 UWB/IMU/VIO 融合定位的关键误差源——公开文献已确认：异步 UWB 源定位、事件触发异步融合定位、Mahalanobis 门控异步 EKF、运动引入的 UWB 异步 TWR 偏差等研究均确认异步偏移必须在重采样前注入、否则被插值掩盖；UWB–IMU 紧组合标定与定位验证异步对齐对融合精度的影响（均有公开文献支撑，含近3年研究）。**异步为什么重采样后仍在（机制说明，S4.1/S4.2 的 A 轴实验意义所在）**：偏移作用于**原始量测的采样时刻**（UWB/IMU/VIO 各自时钟不同步，同一物理时刻三类量测被记到不同的本地时间戳）；重采样只是把样本点取到公共时间轴的整点上，但**每个公共时刻点上取值来自偏移后的原始时刻，因此对齐后 UWB/IMU/VIO 三类量测对应的物理时刻仍互相错位**——这正是异步的本质。模型输入的时间戳字段（UWB/VIO 的 `t` 与 IMU 的 `imu_t`）**本身就承载这段错位信息**（各通道相对公共轴的相位差），risk 头据此识别"三类量测时序不一致"并触发门控；因此 risk 门控的输入特征必须含时间戳语义（与预检 P25、D18 一致），异步偏移若在重采样前注入且时间戳字段保留错位，则 A 轴压力实打实进入模型，否则被插值抹平、A 轴名存实亡。

### S4.1 三传感器定位原理与输出数据规格（文献依据 + 逻辑推理）

> 本节回答三个问题：**三个传感器各自如何定位、各自输出什么数据、谁在融合中承担什么角色**。依据为近3年公开文献共识（三传感器紧耦合融合、传感器布局与数据规格、VIO/IMU 量测建模）与逻辑推理，不在正文标注引用。

| 传感器 | 如何定位（定位原理） | 输出数据 | 在融合中的角色 |
|---|---|---|---|
| **UWB**（DW1000 级，10 Hz） | 标签与 **4 锚（S2 A1–A4）**双向测距（DS-TWR）得**绝对距离**，由已知锚点坐标做三边测量/最小二乘解算位置——提供**绝对位置约束**（全局锚定、抑制漂移、恢复尺度） | `uwb_ranges`（N×4 测距, m）+ `uwb_valid`（N×4 有效掩码） | **绝对约束**：全局锚定 / 漂移校正 / 尺度恢复；紧耦合中用原始 range 残差（不用先解算出的位置，避免信息丢失） |
| **IMU**（消费级，150 Hz） | 对三轴加速度+角速度做积分做航迹推算（dead-reckoning）——提供**高频相对运动**（短时精度高、长期积分漂移） | `imu`（N_imu×6：ax/ay/az/gx/gy/gz，**150Hz 原生，不降采样**）+ `imu_t`（N_imu×1 自身时间戳） | **高频运动先验**：状态传播与预积分因子（紧耦合中不单独解算绝对位置；EKF 用原生 IMU 全速率传播，神经网络在 UWB 帧窗口内聚合高频段） |
| **VIO**（单目+IMU 前端，20 Hz） | 视觉特征 + IMU 联合优化输出**相对位姿序列**（视觉惯性里程计）——提供中频运动约束与朝向（yaw）；单目 VIO 存在尺度/漂移不确定，需 UWB 绝对量测锚定。**诚实口径（与 V0 档一致）**：本实验固定 **V0 健康档**（有效帧率 100%、平移精度 σ≈0.01–0.03m/步，见 S5），**不注入 VIO 尺度漂移/失锁**——"UWB 为 VIO 锚定尺度"是融合设计动机（文献共识），但在 V0 档下**不是本档位的测量压力**，论文不得声称本实验验证了该机制；VIO 尺度/视觉退化压力属 V1–V3 档（不在异步高NLOS实验），如需验证须走协议变更（实验方案变更） | `vio_pos`（N×2/3）+ `vio_yaw`（N×1）+ `vio_valid`（N×1）+ 协方差（V0 健康档有效帧率 100%） | **相对位姿与方向**：视觉几何约束 / 朝向（yaw）链（`vio_yaw` 字段随 S6 契约提供） |

**角色互补（逻辑推理，文献共识）**：UWB 高频缺失、IMU 长期漂移、VIO 尺度不确定——三者单独都不完备，融合后互相补齐；这正是本手册"三传感器输入 + 四头自适应"设计的事实基础。**为什么 IMU 没有输出头（逻辑闭环，防止"IMU 凭什么没有头"疑问）**：IMU 是**高频运动先验**、直接进入骨干作为状态传播/预积分的底料，它不需要像 UWB/VIO 那样的自适应降权（uwb_scaling/vio_scaling）——因为 IMU 不单独解算绝对位置、其误差是积分漂移而非单帧离群；而 IMU 在异步场景下的退化（时钟偏移/采样抖动）已由 **A 轴时间戳语义 + risk 门控**承接（见 S4 机制说明），再设 imu 头会与 risk 头职责重叠、消融时无法正交分离。**输入隔离不变**：模型输入仍只含测距/IMU/VIO/时间戳四类（P11），UWB 输出**用原始测距而非解算位置**（解算位置会预先引入三边测量的误差传播与 NLOS 污染，紧耦合直接用 range 残差是文献主流做法）；CIR/信道特征可进一步提升 NLOS 识别，但作为**可扩展字段**而非主输入（若启用须扩展 S6 契约并走协议变更，属实验方案变更）。

### S4.2 融合方式裁决：紧耦合（文献依据 + 逻辑推理）

**裁决：采用紧耦合（tightly coupled），不采用松耦合。** 依据与推理：

1. **近3年主流收敛于紧耦合因子图/滑窗优化**：UWB+IMU+视觉（VIO）融合的代表工作（因子图 UWB/VIO/IMU、视觉-惯性-测距融合 SLAM、ESKF 紧耦合定位等，2023–2026）均把 `UWB range factor + IMU preintegration factor + VIO/visual factor` 放进**同一优化框架**联合估计状态与偏置——这是当前公开文献的共识主线。**量化依据**：公开文献中紧耦合相对松耦合在融合定位上的增益通常在**分米级到米级 RMSE 差**（NLOS/动态环境下紧耦合可相对松耦合显著压低 P95/尾部误差；松耦合在 UWB 信号遮挡/异步失配时的误差传播会使尾部误差被明显放大），且紧耦合对间歇缺失的保持精度明显更高——本实验用该量级方向作推理依据（具体数值以本实验实测为准，不引用文献具体数字）。
2. **紧耦合直接使用原始量测残差**（range 残差、预积分残差、VIO 相对残差），**避免松耦合"各传感器先解算位置、再按权重合并"造成的误差传播与信息丢失**；在 NLOS、间歇观测（M1 丢包）、短时失锁下，紧耦合因可观测性更强而更稳健。**紧耦合的退化链条（衔接 D17/D22 的机制论据）**：UWB 因 M1 成簇丢包全部缺失时，紧耦合框架自然退化为 **VIO+IMU 相对定位**（EKF 靠运动模型/预积分预测推进——D22，LNN 靠连续时间建模跨越缺失间隙——D17）；VIO 失锁时退化为 **UWB+IMU**（本实验 V0 不注入视觉退化，此路径不激活，但保留在架构设计内）。正因为是**同一优化框架内的量测开关**（factor 失效即被剔除、协方差膨胀），紧耦合才能在传感器间歇缺失时平滑降级而不崩溃——这正是它与松耦合"缺一路就直接砍掉一路独立解算"的本质差异。松耦合的优势仅在工程快速集成（实现简单、算力低），但误差传播更明显、异步与 NLOS 下鲁棒性差——与本实验"**异步 + 高 NLOS**"的压力场景不匹配。
3. **与本项目方法的衔接（紧耦合的具体落地）**：
   - **EKF / Robust-EKF 基线**：按**紧耦合 EKF/ESKF** 实现——状态含（x, y, yaw, 速度/偏差），量测 = UWB range（4 锚）+ VIO 相对位姿，运动模型由 **IMU 150Hz 原生全速率预积分/航迹推算**传播（IMU 不降采样，见 S6/P28；M1 长间隙内用预测保持推进）；R/Q 按 S4 噪声预算标定（P13）；NLOS 下 Robust-EKF 以鲁棒核/协方差调制处理（P17）。
   - **LNN / LSTM / Transformer**：在**输入层做紧耦合式特征融合**——模型输入同时含测距/IMU/VIO/时间戳四类原始量测（P11），由骨干网络内部联合建模（等价于数据级紧耦合）；四个输出头（uwb_scaling / bias / vio_scaling / risk）对三源量测做自适应加权、偏差补偿与门控，正是"NLOS 识别 → 协方差调制/降权 → 鲁棒门控"机制链的落地（与 S4.2 文献中的鲁棒融合组合拳一致：NLOS 识别 + 协方差膨胀/调制 + 鲁棒核/残差拒斥 + 自适应噪声）。
4. **时空对齐是紧耦合成立的前置条件**：时间戳对齐与坐标系统一必须先行——A2/A3 异步偏移在重采样前注入（P28）、世界系/机体系约定固定（S1）、相机-IMU 外参与杆臂（lever arm）在数据生成仿真中按理想值固定并写入 manifest；**异步误差若不建模会被误判为假 NLOS/假离群**（文献共识），这正是 A 轴档位存在的意义。



### S5 轴档位量化（档位与数值见《五轴档位协议定义.md》）
- **A 轴**：A0/A1/A2/A3 四档，异步高NLOS实验用 **A2/A3**；A3 相对 A2 显著更重（异步维度有梯度，支撑 D16）；具体偏移/抖动数值见协议。
- **N 轴**：N0/N1/N2/N3（+消融档 N1.5）五档，异步高NLOS实验用 **N2/N3**（NLOS 档，N2 为墙体级遮挡、N3 为完全遮挡极端，ρ/μ/σ 数值见协议）；各档 ρ/μ/σ 数值见协议。**注：N1.5 是消融实验自定义插值档，不在协议 v27 档位表内**（协议只有 N0–N3），仅用于消融梯度插值，异步高NLOS实验与预检 P23 配置核对不涉及；如需在论文中报告 N1.5，须在方法节注明为自定义插值档。
- **V 轴**：V0/V1/V2/V3 四档，异步高NLOS实验固定 **V0**（健康档）；V1/V2/V3 视觉退化档不在异步高NLOS实验使用；各档具体数值见协议。
- **M 轴**：M0/M1/M2/M3 四档，异步高NLOS实验固定 **M1**（UWB 成簇丢包，间隙区间见协议）；M2/M3 不在异步高NLOS实验使用。
- **K 轴**：K0/K1/K3 三档，异步高NLOS实验固定 **K1**（4 锚非对称欠定，GDOP 区间见协议）；各档锚点布局/GDOP 数值见协议。**注：协议 K1 几何特征为"锚点分布不均、存在共线倾向"；异步高NLOS实验 S2 锚点（A1–A4）实测为"非对称、无共线"，且 GDOP≈1.19 低于协议 K 轴全部档位区间（K0 1.5–2.5 / K1 3–5 / K3 8–15+），按 GDOP 数值无法落位任何一档——K 档归属须作协议裁决项（见 S2：几何特征优先判档 + 裁决项登记表 + 敏感性分析），不静默断言 K1。**

### S6 数据集契约（跑前静态核对对象）
- **文件格式（双速率契约）**：每条序列一个 npz——**UWB/VIO/gt 对齐到 UWB 基准 10Hz（N 行，`t` 为公共时间轴）**；**IMU 保留 150Hz 原生高频（N_imu 行，独立时间戳 `imu_t`），不降采样**。含字段——`t`（时间戳, s, 公共轴）、`uwb_ranges`（N×4 测距, m）、`uwb_valid`（N×4 有效掩码）、`imu`（N_imu×6，ax/ay/az/gx/gy/gz，150Hz 原生）、`imu_t`（N_imu×1，IMU 自身时间戳，承载 A2/A3 偏移错位语义）、`vio_pos`（N×2 或 N×3）、`vio_yaw`（N×1）、`vio_cov`（N×1 或 N×3：**VIO 平移不确定性，字段统一存标准差 σ（单位 m），不存方差 σ²——P13 R 标定与紧耦合 EKF 量测噪声换算时按 σ 口径读取，避免方差异/标准差混口径**；V0 下按 σ≈0.01–0.03 m/步 换算）、`vio_valid`（N×1）、`gt_pos`（N×2）、`gt_yaw`（N×1）、`scene_mask`（N×1：LOS/NLOS/遮挡区标签）、`nl_flag`（N×1：真实 NLOS 注入标记）。**GT 真值精度声明（硬约束）**：`gt_pos`/`gt_yaw` 为本仿真数据集的**无噪声理想真值**（由轨迹几何精确生成，GT 不确定度 = 0），评估时**不引入 GT 不确定度传播**——误差预算（0-4）只含传感器噪声×GDOP 项，不含 GT 噪声项；论文方法节须声明\"仿真 GT 为理想真值，不含实测动作捕捉/激光跟踪的 GT 精度限制\"（若未来用实测数据集，须按 GT 精度（如 VICON 毫米级）纳入误差预算并声明 GT 不确定度 vs 宣称 RMSE 的关系——GT 精度声明与误差预算传播是定位评估报告标准组成部分，均有公开文献支撑，含近3年因子图 GT 轨迹估计、VICON GT 精度评估、GT 不确定度传播研究）。**双速率理由**：IMU 是高频运动先验（S4.1），15:1 降采样会抹掉高频运动信息、并在 M1 长间隙（0.3–2s）下人为放大 EKF 预积分误差——既削弱紧耦合基线的公平性，也让 LNN 的连续时间优势失去对比意义。EKF/ESKF 用原生 IMU 做全速率状态传播；神经网络在 UWB 基准窗口内聚合每帧原生 IMU 段（15 样本：均值/增量/末样本，或独立高频流，见 P28）。
- **契约**：`uwb_valid=0` 统一标记缺失帧——以 M1 人为丢包为主；协议 N 轴可解率 100%（纯偏差描述），N 注入本身不产生缺失帧，仅个别因 μ 上限等原因实际解算失败的帧按协议统一归入缺失（不另立统计）；`nl_flag=1` 单独标记 NLOS 段（与 N 轴注入统计交叉验证，D20 激活热图对齐用）；两标记语义不同、不冲突（与预检 P2 一致）。
- **manifest**：每个 seed 一个 JSON——含场景图、锚点坐标、档位（A2/A3、N2/N3 四组合 A2N2/A2N3/A3N2/A3N3 各 25%）、各组合轨迹数、注入统计（ρ/μ/σ 实际值）、随机源 seed、**外参/杆臂（相机-IMU 外参 T_cam_imu、IMU 相对 tag 中心的杆臂 lever arm，按理想值固定，与 S4.2 依据 4 一致）**；预检 P19/P23 交叉核对的对象。

### S3.5 论文级证据结构（主场景 + 布局随机化泛化层 + 外部真实域，文献逻辑推导）

> **为什么需要这一节**：近3年定位/感知领域报告共识（含 sim-to-real 与随机环境评估基准文献）：**单一受控场景的方法对比容易过乐观**（结论可能只在一个布局下成立）；论文级证据结构要求"至少一个外部/独立验证域"。本实验不自采第二物理场景，改用**两层互补验证**（均按同一协议口径，正文不标注引用）：①**布局随机化泛化层**（同仿真器、随机化场景配置、只判排序稳定性——域随机化/程序化环境生成的报告规范）；②**外部真实域**（公开数据集 MILUV，真实传感器/真实遮挡、只做方法级泛化评估）。三层各自职责与边界如下，论文方法节按此写"数据与验证"小节。

**三层证据结构总表（论文级数据架构，与 S3 轨迹规格衔接）**：

| 层 | 场景/数据 | 规模 | 职责 | 统计推断 | 与主场景共享 |
|---|---|---|---|---|---|
| **① 主场景（受控）** | S1–S3 固定布局（20m×20m、4 锚、4 遮挡区） | 10 seed × 5 方法 = 50 单元；训练 12–15 条/seed、测试 ≥100 条/seed | 受控对比 + 2×2 因子（A×N）+ 全部分层推断（P22） | **全量推断**（配对 Wilcoxon/Holm/2×2 ANOVA/对角配对） | —（基准） |
| **② 布局随机化泛化层** | **同仿真器、随机采样 N_layout 个合法布局**（房间几何/锚点构型/遮挡图/轨迹族至少 3 项随机） | 每布局 5 方法 × 2–3 seed（仅 full 级对比，不做因子）；N_layout ≥ 6（入门）/ 10（推荐） | **只判方法排序稳定**（LNN 最低、full 架构鲁棒性在多少比例布局上成立） | **不做因子推断**；报跨布局稳定率 + 排序一致性 | 同协议（A/N 注入、评估口径）、同冻结模型与超参 |

### S3.5b 布局随机化泛化层与外部真实域落地规范

**布局随机化泛化层（②）落地细节（域随机化/程序化环境生成规范，近3年文献共识）**：

1. **随机层级铁律（硬约束）**：布局随机**只发生在场景/布局之间**（每次采样一整套独立布局配置，在该布局下生成完整训练/测试集），**禁止在场景内轨迹之间随机布局**——场景内随机会把布局差异混入方法对比误差项、破坏配对性，因子推断被污染；场景间随机才是"跨配置泛化扫描"。
2. **合法性筛子（每个采样布局必须先过，不过重采样，复用 S2 沙箱枚举逻辑）**：①房间几何合法（尺寸区间内随机，净高/凸包约束）；②**4 锚构型合法且 GDOP 可判**（锚点坐标随机采样后按 GDOP 几何校验，不合格重采样——锚点几何是定位误差的决定因素，公开文献共识）；③遮挡区合法（数量/位置随机、面积占比 ≤50%、不遮挡锚点直射基线）；④轨迹族合法（转弯/速度/不出凸包）；⑤**与主场景布局差异 ≥ 阈值**（房间尺寸、锚构型、遮挡图、轨迹族至少 3 项改变，否则退化为重复测量）。
3. **规模档位**：入门 N_layout=6、推荐 N_layout=10（full + 2 个最强基线 LSTM/EKF × 2–3 seed 即可，泛化层只判排序不做因子推断，不需要主场景同等功效）；每布局全部参数 + 随机根种子写入该布局 manifest。
4. **判定与报告口径（硬约束）**：②只报——①**稳定率**（LNN 在 N/M 个布局中 RMSE 最低 / full 架构鲁棒性）；②**跨布局排序一致性**（Kendall τ 或排序重复率）；③布局参数 vs 方法排序的散点/箱线（论文稳健性图）。**②的结论不得写成"因子/机制结论"**——因子推断只在主场景①做，②只回答"排序是否跨布局稳定"。
5. **与主场景的数据独立性**：②每个布局的轨迹**必须重新生成**（同协议、同代码、只换 scene 配置参数——scene manifest 化），禁止复用主场景轨迹或"换标签"；训练/验证/测试划分在每个布局内各自进行。

**MILUV 外部真实域（③）落地细节（真实数据适配规范，近3年文献共识）**：

1. **适配边界（硬约束）**：只做格式对齐（重采样到公共频率、坐标系对齐到真值系、时间戳同步、字段映射到 S6 契约同构），**不改网络结构、不调协议档位、不动冻结超参**（sealed-exam 纪律，见 Pre-2）；MILUV 为 UWB 测距 + IMU（150Hz 级）+ Vicon 毫米级真值，锚点 6 个——**若模型输入按固定锚数设计，取固定 4 锚子集（GDOP 择优，写入 manifest 并声明）或确认模型锚数无关后全量使用，二选一并在论文声明**。
2. **评估口径**：与主场景同口径（对齐后 / warm-up 剔除 / 2D 世界系 RMSE + P95）；利用 MILUV 的 LOS/NLOS 遮挡标注做**分段分解报告**（LOS 段 vs NLOS 段分别报，与手册分场景评估对齐）。
3. **配对单位（硬约束）**：以 MILUV 的**独立实验（次）为配对单位**（36 次独立实验 = 每方法 36 个轨迹级配对样本），**禁止把同一次实验切片成多段当独立样本**（伪独立）；功效边界如实声明（36 对属"十几到几十对"区间，作补充验证可接受，不夸大为主结论）。
4. **禁止事项**：③只做方法级 full 对比（LNN vs 基线），**不做消融/不做因子分析**（消融归因只在受控域①成立）；禁止在 MILUV 上调参挑结果（sealed-exam）；适配代码与评估代码走同一 code freeze（Pre-2/I-7）。
5. **结论边界声明（论文必写）**：论文数据小节声明"受控协议域 = 因子与消融结论来源；布局随机化层 = 跨布局排序稳定性；MILUV 真实域 = 方法级真实泛化验证（36 次独立实验）；三层不混用结论"。

**三层数据独立性铁律（硬约束，跨层复用禁止）**：①主场景、②随机化布局、③MILUV 的轨迹**互不复用**；②与①共享协议与代码但**不共享轨迹**；③是第三方数据原样使用。数据独立才谈"跨场景/跨域验证"，协议一致才谈"可比"，模型冻结才谈"公平"。

**执行入口**：①主场景照常走本文档全部流程；②③为**新增验证层**，其实现/冒烟/统计校验复用同一套 I-1–I-5/P22 脚手架（场景 manifest 化后 S9 校验按各布局专属期望执行）；②③的跑后判定只走 A-1 落窗/排序类判定，不进因子类判定。此三层结构写入论文"数据与验证"小节，作为场景数=1 的论文级证据结构出口（对照"单环境对比过乐观"的审稿质疑，本结构以"受控域 + 布局随机化 + 真实外部域"三层互补回应）。

- P4（K1 GDOP：几何特征判定 + 协议裁决项，见 S2）↔ S2 锚点坐标；P5（轨迹不出域）↔ S1 凸包缓冲；P28（多速率重采样）↔ S4 传感器规格；P11（输入隔离，紧耦合原始测距输入）↔ S4.1/S4.2；P13（R/Q 标定）↔ S4 噪声预算；P3/D17（M1 长间隙区间，见协议）↔ S5 M1；P25（A2/A3 时间戳语义）↔ S5 A 轴档位；P27（激活热图）↔ S6 `nl_flag`/`scene_mask`。

### S8 数据生成流水线（注入顺序契约）

> 各轴注入的**先后顺序**直接影响 P2（可解率边界）、P3（M1 成簇）的核对对象。此节钉死生成顺序，避免"NLOS 不可解帧"与"人为丢包"在缺失统计上重复或漏算。

**生成顺序（每条序列）**：
```
① 场景/轨迹生成 → ② 传感器量测仿真（UWB/IMU/VIO 原始） → ③ A 轴异步偏移注入（重采样前） →
④ N 轴 NLOS 偏差注入（按遮挡区） → ⑤ M 轴缺失注入（人为丢包） → ⑥ 统一重采样到公共时间轴（UWB/VIO/gt → 10Hz；**IMU 保留 150Hz 原生，不降采样，写 `imu_t`**） →
⑦ 写 npz + manifest
```
- **A 注入在重采样前**（P28）：偏移作用于原始时间戳，重采样时才体现错位，否则偏移被插值吃掉。
- **N 先于 M**：先按 `scene_mask` 对遮挡区施加 NLOS 正偏差 + 噪声（`nl_flag=1`）。协议 N 轴定义**可解率 100%**（纯偏差描述），故 N 注入本身不产生缺失帧；若个别帧因 μ 上限等原因实际解算失败，按协议 M 轴统一口径**归入缺失**（不可解帧 = 缺失，见协议 M1"含 NLOS 引起的不可解帧，统一为缺失注入"）。
- **M 后于 N**：在已施加 N 偏差的序列上再施加 M1 成簇丢包（缺失率与间隙区间见协议）。**缺失以 M1 注入为准**（协议 M1 口径）：N 注入本身可解率 100% 不产生缺失帧，个别实际解算失败才归入缺失，`uwb_valid=0` 统一标记，不再人为分列统计。
- **重叠规则**：`nl_flag=1` 与 `uwb_valid=0` 同时保留——前者记录"该帧是 NLOS 段"（供 D20 热图交叉验证），后者记录"该帧无测距值"（缺失），两标记语义不同、不冲突。
- **V 轴不注入**（异步高NLOS实验固定 V0）：VIO 帧全程有效，`vio_valid=1`；M 轴缺失只作用于 UWB（M1），VIO 缺失仅在 M2/M3（不在异步高NLOS实验）出现。

### S9 数据生成校验脚本契约（生成后、预检前必跑）

> 把 P1–P6 的静态核对固化成脚本，生成完每批数据就跑一次，不合格直接重生成，**不让坏数据流到预检**。

**数据适配性检查（fitness-for-purpose gate，DQ-1–DQ-4，S9 扩展——数据"正确"之外还要"适合研究问题"）**

> **为什么需要这一节**：S9 表格校验的是"数据是否**按协议正确生成**"（正确性 gate）；但数据"正确"不等于"**适合研究问题**"——若四组合难度梯度不足、NLOS 信噪比太低、分布不可学、样本量不足，实验会"认真执行仍失败"且失败原因在数据本身而非方法。数据审计（data audit）与"数据集是否适配研究问题"（fitness-for-purpose）评估是数据为中心（data-centric）方法论的核心共识：数据质量（缺失/噪声/偏差/污染/泄漏）是评估虚高与负结果的首要风险源，数据审计必须**前置到实验准备/数据生成阶段**，负结果报告须区分"方法失败"与"数据不支持该问题"——均有公开文献支撑（含近3年数据为中心（data-centric）方法论综述、数据集质量评估框架、数据性失败归因研究），正文不标注引用。**DQ 检查在 S9 正确性校验通过后、进入 Step 1 前执行**；不合格 → 先修数据（重生成/调轨迹设计/走协议变更），修不通才允许"缩小声明范围"（见 R-1 ⑤、R-5）。

## Part 2 · 跑前预检（39 项，八层）

### 第一层 数据正确性（1–6）

1. **混合池构成统计**：异步高NLOS实验为 A2/A3 × N2/N3 四组合池（A2N2/A2N3/A3N2/A3N3 各 25%）；N2/N3 的 ρ/μ/σ 与 A2/A3 的偏移数值按协议核对（N2 物理对应墙体级遮挡、N3 对应完全遮挡/穿墙）。打印各组合实际轨迹数量与 ρ/μ/σ（误差超 10% 或任一组合比例偏差超 5% 重生成）。
2. **缺失来源与可解率口径**：按协议，N 轴纯偏差描述、可解率 100%，不可解帧统一归 M 轴缺失注入（M1 含 NLOS 引起的不可解帧，统一为缺失）；检查训练/测试的 `uwb_valid=0` 分布与 M1 缺失率一致，`nl_flag` 与 N 注入统计可交叉验证。
3. **M1 成簇丢包**：UWB 按协议 M1 缺失率成簇注入、间隙区间见协议，非均匀撒点；协议 N 轴可解率 100%（N 注入本身不产生缺失帧），缺失总量以 M1 注入为准；若个别帧因 μ 上限等原因实际解算失败，按协议统一归入缺失（M1 含 NLOS 引起的不可解帧，统一为缺失注入）。
4. **K1 GDOP**：用锚点坐标算 GDOP 直方图，**与 S2 实测一致（均值 ≈1.19，偏差 ≤10%）**；K 档归属按**几何特征**判定——**当前锚点为"非对称、无共线"，与协议 K1"分布不均、存在共线倾向"不完全一致，且 GDOP≈1.19 低于协议 K 轴全部档位区间（K0 1.5–2.5 / K1 3–5 / K3 8–15+），按 GDOP 数值无法落位任何一档（S2 数学验证：1.5m 凸包缓冲下 GDOP 均值到不了协议 K1 的 3–5，也更低不了 K0 下限的物理意义）**，K 档归属为**协议裁决项**（S2 数学验证 + 裁决项登记表 + 敏感性分析，见 S2），**不按区间硬判、不因达不到 3–5 判失败、不自行断言 K1**（与 S9、0-6、Part 4 K 轴裁决一致）。
5. **轨迹不出域**：真值轨迹全程在锚区凸包内，无出域段。
6. **规模与划分**：训练/测试序列数符合设计（训练 12–15 / 测试 ≥100·四组合各 ≥25 / seed）；划分按整条序列、训练与测试无重叠。

### 第二层 坐标系/实现（7–13）

7. **旋转链路**：纯 IMU 积分走"绕圈回起点"，直线 vs 转角对比，偏差方向符合 yaw 约定、不反向不爆掉。
8. **单位与归一化**：dyaw 用 rad；输入角归一化到 [-π,π]（或等效范围），0.1rad 输入 → 10 步后朝向 ≈1rad；距离用 m；无 ×57/×100 静默错误。
9. **评估对齐**：算 RMSE 前先做 Sim(3)/Umeyama 轨迹对齐（必须，不是可选）。
10. **维度**：只算 2D（x,y），不混 Z。
11. **输入隔离**：模型输入只含测距/IMU/VIO/时间戳，不含锚点坐标、不含 geom_condition 标签（见 S4.1：UWB 用**原始测距**而非解算位置——解算位置会预先引入三边测量误差传播与 NLOS 污染；紧耦合式输入与本手册融合裁决一致）；**IMU 以 150Hz 高频段聚合特征（均值/增量/末样本）或独立高频流进入骨干，不降采样（见 P28 双速率契约）**。
12. **训练/测试注入对称**：训练集含与测试集同分布的 NLOS 大脉冲（各方法都见得到压力）。
13. **R/Q 匹配**：滤波类方法的 R/Q 与注入噪声统计一致，不拍脑袋。


### 第三层 方法公平性（14–18）——异步高NLOS实验特有

14. **三网络共享同一套头**：LSTM/Transformer 必须与 LNN 用完全相同的 4 个头结构，只换骨干；检查代码，头不是各自独立实现。
15. **训练配置公平（per-method tuning）**：LNN/LSTM/Transformer 同数据、同 seed、同优化器、同 epoch、同早停标准；**lr/调度器等超参允许各方法独立调优（per-method tuning），但调优预算一致**（同一验证集、同等调优次数/算力）——这是审稿认可的标准做法，既保证公平又避免"LNN 用默认 lr 吃亏"（与 D10 一致）。
16. **EKF 实现正确性**：标准 EKF 更新、状态/观测模型、R/Q 初始化合理；状态变量（x, y, yaw, 速度/偏差）与 S4.2 一致（速度/偏差为可选扩展状态，若不估计速度则运动模型退化为位置-朝向传播，须在实现说明中声明）；**初始化协议（紧耦合 EKF 关键环节，文献共识——UWB-VIO 初始化是融合定位的成败环节，含近3年 UWB-VIO 初始化与可观测性分析研究）**：初始位置取序列首帧 UWB 三边测量解（≥3 锚有效时），若首帧锚数 <3 或 `uwb_valid=0` → 延迟初始化：用零位 + 大协方差 P0（位置 100m²、yaw π² 量级），待首帧三边测量可行时重置；初始 yaw 取 VIO 首帧朝向（`vio_yaw[0]`），VIO 无效时置 0 + 大协方差；初始速度取零；P0 对角取上述不确定性，写入实现说明（P13 R/Q 与 P0 一并标定）。
17. **Robust-EKF 实现正确性（必跑）**：Huber 核/加权应用正确，不是简单加大 R；与 EKF 的关系作为独立对比实验报告，不作胜负预设。
18. **基线不是裸模型**：确认 LSTM/Transformer 确实带头运行——否则 LNN 赢它们="4 个头 + 液态骨干"双重优势，对比不公平。

### 第四层 统计脚手架（19–23）

19. **seed 体系一致**：轨迹/噪声/注入/划分各一随机源，全部固定并写入 manifest；**确定性模式启用（CUDA deterministic/benchmark=False、固定线程数与数据加载 worker seed）**，同配置同机重跑逐 bit 相同（跨机因硬件差异允许浮点末位差，以同一机重跑为准；seed 数量直接影响统计功效与结论稳健性、多 seed 评估是统计推断稳健性的必要条件、seed 固定+披露是可复现性标准组成部分、样本量/功效决定单次实验能否支撑强结论——均有公开文献支撑，含近3年研究）。**精度模式统一声明（硬约束）**：**TF32 开关显式设置并写入 manifest**（`torch.backends.cuda.matmul.allow_tf32` 与 `torch.backends.cudnn.allow_tf32` 显式 True/False，三网络与 EKF/Robust-EKF 共用同一设置）；**三网络训练/评估精度模式完全一致**（同 FP32 或同 TF32，禁止 LNN 用 FP32、LSTM 用 TF32 等精度不一致）；**默认启用 FP16/AMP 混合精度（训练加速，文献依据：Micikevicius et al., Mixed Precision Training, arXiv:1710.03740——前向/反向在 FP16 上执行、主权重保持 FP32、loss scaling 保数值稳定，可显著缩短训练时间且精度不劣化）**：三网络与 EKF/Robust-EKF 共用同一 AMP 设置，**禁止 LNN 用 AMP、LSTM 用 FP32 等精度不一致**；确定性模式下 AMP 须与 CUDA deterministic 兼容并在冒烟阶段验证同配置重跑逐 bit 相同（P19 既有要求不变）；AMP 开关写入 manifest（Pre-4 校验和覆盖）；精度模式写入 Pre-4 校验和覆盖范围与论文方法节——低精度（TF32/FP16）与确定性子开关是跨机/跨版本不可复现的关键来源（公开文献共识，含近3年数值确定性与浮点可复现性研究），正文不标注引用。
20. **配对样本对齐**：各方法评估按"同一测试轨迹 × 同 seed"配对；Wilcoxon 是配对检验。
21. **序列级划分防泄漏**：划分按整条序列，训练/测试无重叠；A2N2/A2N3/A3N2/A3N3 四组合轨迹数量各自平衡。**归一化/标准化防泄漏（硬约束）**：模型输入（测距/IMU/VIO/时间戳）的归一化统计量（均值/方差/min-max 等）**只用训练集计算**，测试集一律用训练集统计量变换；禁止用全量或测试集统计量（滑动窗口归一化时窗口内不得含未来/测试帧信息）——时序数据归一化泄漏是评估虚高的常见来源、训练/测试统计量必须隔离（公开文献共识，含近3年时序泄漏防护与基准净化研究），冒烟与全量统一执行。
22. **统计脚本就位**：输出 mean±std（over 10 seed）、P95、P50（median）、Δ vs LNN、Wilcoxon p 值、95%CI；两两比较（五方法共 10 对）附 **Holm-Bonferroni 多重比较校正**——多方法对比不做校正会放大假阳性（多重比较校正是统计推断标准步骤、Holm-Bonferroni 为稳健默认、ML 比较应配套统计检验+CI+校正、非参数检验应配合 Bonferroni-Dunn/Holm/Hochberg 控制族错误率——均有公开文献支撑，含近3年研究）；**另输出四组合切片统计（A2N2/A2N3/A3N2/A3N3 各组合均差 ±std、P50/P95 一并输出）+ 2×2 ANOVA（A 轴 × N 轴，验证 A×N 交互）+ C1（A2N2 轻异步×轻 NLOS）vs C4（A3N3 重异步×高 NLOS）对角配对对比（配对 Wilcoxon，验证对角梯度 D16）**——异步高NLOS实验为 A2/A3 × N2/N3 全 2×2 网格，N 轴含 N2/N3 两档，**适用 2×2 ANOVA**（A×N 交互存在），对角梯度由 C1 vs C4 承担；**ANOVA 须报告交互项 F 值、p 值、效应量（partial η²），并检查方差齐性（Levene）；若方差齐性严重违反，ANOVA 结果以非参数替代（如 Aligned Rank Transform 或对四组合做 Kruskal-Wallis + 事后 Dunn）作为稳健性后备，正文报告两种口径**（方差分析的前提检验与效应量报告是统计报告标准组成部分——有公开文献支撑，含近3年研究）。**整体-局部分层推断（two-step: global then pairwise，硬约束）**：①**全局检验先行**——五方法整体差异先由全局检验承载（2×2 ANOVA 的主效应/交互 + 五方法整体置换检验或 Friedman 检验），全局不显著（校正后 p≥0.05）时，**两两 Wilcoxon 一律降级为探索性（exploratory）报告**，不得宣称"某方法显著优于某方法"；②**全局显著才可解读两两**——全局显著后，两两 Wilcoxon（10 对，Holm-Bonferroni）用于定位差异来源；③**校正后 CI 同步声明**——Holm 校正针对 p 值族错误率，**95%CI 未做多重比较调整时必须显式声明"CI 未校正、解释从保守"**（若报告校正后 CI 须注明方法，如 Bonferroni 校正置信区间）——整体-局部分层策略（全局检验保护族错误率、事后两两定位）与校正后 CI 报告规范是多重比较推断的标准做法（公开文献共识，含近3年多重比较综述与两两比较指南），正文不标注引用。**功效与样本量声明（论文必报）**：论文须报告目标效应量（最小可检测相对提升，按 A-2 的 40% 下限折算）、显著性水平 α=0.05、功效 power≥0.8、以及 **10 seed × ≥100 测试轨迹**对应的统计把握说明（含预估方差来源：冒烟/先导实验）；10 seed 不足支撑功效时如实声明并给出**扩样路径（只增不减：加 seed/轨迹至功效达标，规模恒 ≥ 论文级 10 seed × ≥100/seed，S3 硬约束——不存在"收窄/降档"方向的出口）**——样本量与功效决定单次实验能否支撑强结论、效应量+CI+功效是统计报告标准组成部分（公开文献共识，含近3年样本量决策与功效分析研究）。**分析单位与样本独立性声明（硬约束）**：滑窗 W=128 步（步长默认 1 帧）使相邻窗口重叠 127/128，**帧级误差样本高度自相关、不满足 i.i.d.**——所有统计检验（配对 Wilcoxon、2×2 ANOVA、TOST、贝叶斯因子）**必须以轨迹级为分析单位**（每 seed 每测试轨迹汇总一个 RMSE 值，10 seed × ≥100 轨迹 = 每方法 ≥1000 个轨迹级样本，四组合每组合 ≥250 个）；帧级 mean/P50/P95 仅作描述性报告；若必须报告帧级检验 → 用按轨迹聚类的 bootstrap 或 cluster-robust 方差并在论文声明检验单位与自相关处理——窗口重叠导致的样本非独立与检验单位选择是统计推断正确性的关键环节（公开文献共识，含近3年时序评估与检验单位研究），正文不标注引用。**先导实验（pilot）定位声明（与冒烟分工，方案冻结前完成）**：冒烟（Step pilot/feasibility 方法学研究）；pilot 估计的方差可用于 DQ-4/本项功效核算，但正式结论只来自冻结后全量 10 seed 数据；pilot 结果不写入论文结果表（可入方法节可行性说明）。
23. **配置一致性**：跑实验用的 YAML 档位矩阵与生成数据的 manifest 交叉核对，不出现"数据按 N2/N3 生成、实验只按轻档读"或"数据 A2/A3 混合、实验以为只 A2"。

### 第五层 稳定性/接口（24–27）

24. **无 NaN/Inf/梯度爆炸**：冒烟训练时监控 loss、权重范数。
25. **A2/A3 时间戳语义**：时间戳单调递增；A2/A3 的偏移与抖动数值按协议生效（见 S5、协议 A 轴）；重采样不引入额外误差。
26. **VIO payload 真接入**：`vio_valid` / scaling 字段真实传给模型（V0 下 `vio_valid` 全 1；scaling 为 VIO 置信度接口，V0 健康档下恒为 1——协议 V 轴 scaling 退化（0.3–0.7/→0）属 V1–V3 档，不在异步高NLOS实验；但接口必须真实接通、不得写死省略，否则消融 vio_scaling 头时无从移除）。
27. **激活统计可视化**：导出四头激活统计/热图，判断各方法是否真实使用头信息（模型激活分析是定位模型诊断的可行手段、可解释性分析支撑机制归因、时序模型可解释性分析框架成熟、Transformer 注意力统计检验已有方法学——均有公开文献支撑，含近3年研究）。

### 第六层 数据管道（28–31）

28. **多速率重采样（双速率，IMU 不降采样）**：UWB(10Hz)/VIO(20Hz) 统一到**公共时间轴（基准 10Hz，逐帧对齐 UWB 时刻）**；**IMU 保留 150Hz 原生（`imu_t` 独立时间戳，不插值到 10Hz，不降采样）**——S6 双速率契约；UWB/VIO/gt 输出行数 N 以 UWB 帧数为准（**10Hz×120s≈1200 行/序列，S3 论文级基准 120s**），`imu` 为 N_imu 行（**150Hz×120s≈18000 行/序列**）；A2/A3 注入发生在重采样**前**（UWB/VIO 与 `imu_t` 各自按协议偏移）；W=128 步 ≈ 12.8s 物理窗口（10Hz 基准下），warm-up 前 10s ≈ 100 帧；**神经网络输入：每 UWB 帧对应窗口内的 IMU 高频段（15 个原生样本）以聚合特征（均值/增量/末样本）或独立高频流喂入骨干，EKF/ESKF 用原生 IMU 做全速率预积分/状态传播（不降采样）**。**重采样方法声明（硬约束）**：UWB/VIO 重采样到 10Hz 公共轴的插值方法**统一指定**——本实验采用**最近邻（nearest-neighbor）对齐到 UWB 帧时刻**（UWB 10Hz 帧时刻本身是采样点，VIO 20Hz 取最近时刻、gt 同轴直接对齐），**不使用线性/样条插值生成测距或 VIO 值**（插值会人为平滑测距噪声与 NLOS 偏差跳变、引入伪延迟——插值/重采样引入的伪延迟、频谱混叠与评估偏差是多传感器对齐的公开文献共识，含近3年时间对齐与重采样研究）；此声明写入论文方法节；如需评估插值敏感性 → 作为敏感性分析项（S2 裁决项登记表同类留痕），不改变主实验口径。
29. **窗口化正确性**：W=128 步不跨序列边界；warm-up 前 10s 不进评估窗口；**IMU 高频段（每 UWB 帧窗口内的 150Hz 原生样本）不得跨序列拼接，序列首尾的 IMU 段不足 15 样本时按零填充并记入掩码（不引入跨序列污染）**。
30. **划分先于窗口化**：按整条序列划分，再窗口化，避免同一轨迹窗口跨集。
31. **边界/极端情况**：空轨迹、极短序列、M1 长间隙落在首尾，不产生人工尖峰/除零。

### 第七层 训练一致性（32–35）

32. **同 seed 初始化**：LNN/LSTM/Transformer 用同一 seed 的权重初始化。
33. **优化器/调度器/早停一致（超参按 per-method tuning）**：所有方法同优化器、同 epoch、同早停标准、**同 batch size（=16，三网共用，文献依据：LTC 原文 Table S1 "Minibatch size is 16 for all models"（AAAI 2021）为基准，UWB/IMU 序列模型公平对比文献一致采用同 batch 惯例）**；lr/调度器按各方法独立调优、调优预算一致（见 P15、D10）。**checkpoint 选择协议（统一规则，防"暗中选优"）**：三网络统一取**验证集最优（best-val）checkpoint** 用于最终评估（同一验证集、同一提前停 patience、同一选择准则），**禁止各方法自由选点**（best-val vs last-epoch 混用会直接破坏公平对比——固定预算+统一 checkpoint 选择是公平基准的标配，公开文献共识，含近3年 benchmark/评测协议研究）；best-val 选择与早停共用同一验证集（不得用测试集选点）；若个别方法验证集最优与最后 epoch 差异过大（>5% 相对差），记录并说明原因，不作为常规报告口径。
34. **无严重过拟合**：训练 loss 收敛，验证 loss 不反升。
35. **头实现一致性**：三个网络的 4 个头参数结构逐层一致，只骨干不同（防止实现偏差污染对比）。

### 第八层 评估口径（36–39）

36. **RMSE 口径声明**：报告帧级 mean±std、P50（median）、P95（轨迹级 std 可另列），论文/表中声明口径不混用；室内定位报告惯例为分布级指标（CDF/P50/P95——有公开文献支撑，IPIN 等竞赛亦用 CDF/分位数评估；近3年 UWB 定位多指标基准强调 percentiles/CDF、median+P90+CDF 联合报告、误差 CDF 到 P95 为报告惯例、UWB 单锚统计多径模型报告误差分布——均有公开文献支撑）。**离群值与重尾稳健评估声明（硬约束）**：UWB/NLOS 测距误差呈重尾/离群常态（NLOS 大偏差脉冲、M1 长间隙边缘帧），RMSE 均值易被极端值放大——论文必须声明离群值处理策略：**不删样、不截尾、不做 winsorization**（保留全部帧，删样/截尾须逐条说明理由与占比，否则视为选择性报告）；同时报告**稳健补充指标：MAE、截尾均值（trimmed mean，如 5% 双侧裁剪，须声明裁剪比例）、中位数误差**，与 mean±std/P50/P95 并列——重尾误差下中位数/分位数/截尾均值比单一均值更能反映真实性能，稳健估计与离群值策略声明是评估报告标准组成部分（均有公开文献支撑，含近3年重尾/离群评估与稳健统计研究）。**相对提升报告规则（硬约束）**：论文凡报告\"LNN 相对 EKF 提升 X%\"，必须**同时报告绝对差（m）、基线值（EKF 绝对 RMSE）、百分比提升、95%CI**（相对变化的意义依赖基线水平，单报百分比易夸大——方法学文献共识：百分比改善须配绝对差与 CI、基线相关的相对变化报告规范）；绝对差+CI 是主口径，百分比仅作辅助表述。**噪声分布假设声明（联动 S4）**：论文声明噪声分布假设（LOS 段高斯、NLOS 段\"时变正偏差+附加抖动\"，见 S4）及其对评估口径的影响——非高斯/重尾偏差由 NLOS 注入承载，评估按本项稳健口径执行（非高斯噪声对定位精度评估的影响、重尾误差模型实证——均有公开文献支撑）。
37. **warm-up 剔除**：前 10s 不进入 RMSE 计算。
38. **误差在世界系算**：2D 世界系误差，不是机体系。
39. **结果持久化**：每实验存配置 hash、seed、完整指标、git commit，可逐行复现。



### 论文级验收执行规范（RZ-0–RZ-3，清场→重生成→重训→验收，论文级实验的唯一验收路径）

> **为什么需要这一节**：论文级实验的验收标准是"**用论文级规模（10 seed × 5 方法 = 50 单元、训练 12–15 条/seed、测试 ≥100 条/seed、120s 基准，见 S3）跑出的结果**"。任何早于论文级正式执行的旧数据、旧权重、旧结果（含冒烟阶段临时数据/权重、早期试跑产物）**一律不得进入最终统计与论文表格**——否则"验收"验收的是混合产物，审稿人按 manifest 复核即穿帮。本节以 **RZ-0 清场 → RZ-1 重生成 → RZ-2 重训 → RZ-3 验收** 四道硬 gate 钉死"从零开始、纯净可溯"的论文级执行路径（数据生命周期管理、artifact 隔离、版本化数据集的公开文献共识，正文不标注引用）。**与 R-1–R-5 的关系（编号说明）**：R-1–R-5 是"认真执行仍失败"后的**失败归因与重跑决策**（针对具体失败单元）；RZ 是**论文级正式执行的入口/出口规范**（针对整批实验的纯净性）——RZ 不替代 R，R 不替代 RZ，二者按各自触发条件执行。

**时序总览**：`RZ-0 清场`（每次运行前清空仿真数据集与权重，流程起点；诊断轨轻量清场 / 验收轨完整清场）→ 实验准备 Pre-1–Pre-6 → 实现完成清单 I-1–I-5 → 数据生成与预检（S9/DQ）→ 冒烟（临时小数据）→ 统计脚本冒烟验证 + 实现冻结（code freeze）→ `RZ-1 重生成`（用冻结生成器 + 论文级规模参数重新生成全部数据，冒烟数据作废）→ `RZ-2 重训`（用新数据从头训练全部 50 单元，旧权重一律禁用）→ 全量结果完整性汇总 G-1–G-5 → 执行合规审计 E-1–E-6 → 可视化速查 0-V1–0-V6 → 八层诊断 D1–D31 → `RZ-3 验收`（A-1–A-9 + 泛化/真实域层判定，全部针对新数据新权重）。

> **实验两轨语义与「每次跑前清场」总纪律（先读本节，消除"全量/非全量/诊断/验收"的一切歧义）**：
> ① **诊断轨（非全量）——允许，但永不进论文**：冒烟、quick 校准、可视化诊断性重跑、审计抽查复跑、失败排查与归因前的探针实验等**诊断性实验允许非全量**（短时长/子集/少 seed），唯一目的是**发现并定位问题**（管线通不通、失败在哪一层、数据还是方法）；其数据/权重/结果**永不进入论文统计、图表与验收**——"冒烟数据在 RZ-1 前作废"是该原则的显式实例，同一原则扩展到**一切诊断产物**（用后即弃或隔离归档，禁止并入任何正式数据）。
> ② **验收轨（论文级全量）——唯一算数的实验**：只有「清场 → 重新生成论文级数据 → 从头重训 → A-1–A-9 验收」的**论文级全量实验**产生论文数字；诊断轨的任何结果**不得**以任何形式并入、替代或"补充"验收轨数据。
> ③ **每次跑实验前都清空仿真数据集与权重（总纪律，不分轨）**：**每一次运行之前**——诊断轨实验（冒烟/校准/探针/抽查复跑）跑前、验收轨（论文级正式执行）跑前、以及任何 R 系列重跑/补跑前——都必须先清空**活动数据目录中的仿真数据集**（训练/验证/测试 npz + manifest）与**活动权重目录**（checkpoint/权重），删除或迁移 `archive/` 物理隔离，保证实验脚本任何路径读不到旧产物；**诊断轨清场执行清场清单即可（不必写 decision log），验收轨清场必须逐项留痕（下节动作清单 + decision log）**。**不清场不跑实验**——否则本次结论可能被旧数据/旧权重污染，且诊断产物可能被误带入验收轨。

#### RZ-0 清场 gate（每次运行前清空仿真数据集与权重；旧数据/旧权重/旧结果清零，流程起点）

**目的**：确保本次实验结果是"从零开始、纯净生成"，不被任何旧仿真数据、旧权重、旧结果污染——**无论诊断轨还是验收轨**。**触发时机（每次运行前，三强制点缺一不可）**：①**诊断轨每次跑前**——冒烟/quick 校准/诊断性重跑/审计抽查复跑/R 系列探针跑前，先清空活动目录的仿真数据集与权重（诊断轨轻量清场，见下方清场动作清单，不必写 decision log）；②**论文级正式执行前（Pre-1 之前）**——完整清场逐项留痕；③**冒烟通过、code freeze 之后进入 RZ-1 之前**——冒烟产生的临时数据/临时权重也必须一并清场（冒烟只验管线，其数据/权重不进入最终统计——与"测试轨迹重新生成：全量 10 seed 的测试轨迹必须全部重新生成，不能用冒烟那 ≥12 条凑数"同一原则的整批化执行）。**任何一次不清场就运行 → 该次运行按无效处理，其产物一律不得进入统计与验收。**

**清场动作清单——两档模式**：
- **诊断轨轻量清场（每次诊断跑前，3 项）**：①清空活动数据目录全部旧仿真 npz + manifest（删/迁 archive，脚本读不到）；②清空活动权重目录全部 checkpoint（删/迁 archive）；③清场动作记一行到运行日志（时间戳/操作人/目录）。诊断轨清场**不必写 decision log、不必逐项 hash 留痕**，但必须让实验脚本**任何路径读不到旧产物**。
- **验收轨完整清场（论文级正式执行前 + 冒烟后进 RZ-1 前，6 项逐项留痕，缺一不可）**：
1. **旧仿真数据集清零**：全部旧训练/验证/测试 npz + manifest 从活动数据目录**删除或整体迁移至 `archive/`**（物理隔离；迁移必须保证实验脚本**任何路径都读不到 archive**，否则视为未清场）；逐目录 `find` 清点并记录（路径、文件数、总字节、删除/迁移时间戳、操作人）。
2. **旧权重清零**：全部旧 checkpoint/权重文件从活动模型目录删除或迁移至 archive；**禁止任何"热启动/续训/预训练初始化"路径**指向旧权重。
3. **旧结果清零**：全部旧指标/日志/统计输出/旧验收表/旧论文表格草稿的旧数字**一律作废**（可从 archive 保留作为过程记录，但**不得出现在论文级最终统计的任何输入路径**）；旧统计脚本输出文件删除或归档。
4. **校验和清单同步**：Pre-4 校验和清单更新为"活动清单只含新数据/新权重的 hash"，旧 hash 移出活动清单。
5. **清场动作留痕（硬约束）**：清场清单（目录、文件数、字节、hash、时间戳、操作人、archive 路径）写入 decision log（Pre-2），并在论文可复现性附录中列一行"数据/权重/结果自清场后重新生成"。
6. **清场完成判定（自动核验）**：运行脚本确认——活动数据目录、活动权重目录、活动结果目录内**无任何旧 npz/权重/结果文件**（或仅有 archive 软链且实验脚本显式排除）；任一旧文件可被实验管线读取 → 清场未过，继续清。

**出口**：RZ-0 全部动作完成并留痕 → 进入实验准备（Pre-1–Pre-6）；任一未过 → 继续清场，**不得带旧产物进入任何论文级流程**。

#### RZ-1 重生成 gate（用冻结生成器 + 论文级规模重新生成全部数据）

**目的**：用**同一套 code freeze 后的生成器代码 + 论文级规模参数**重新生成全新数据集；**任何旧数据集一律不得复用**（哪怕旧数据本身合格），论文级结论必须来自这批复现可查的全新数据。**触发时机**：冒烟通过 + 实现冻结（code freeze）后、全量训练前。

**动作清单**：
1. **生成器代码冻结确认**：数据生成器代码与冒烟通过的 git commit 一致（code freeze 覆盖训练/评估/统计/**数据生成**四类代码）；生成器若有任何改动（哪怕一行）→ 解冻→修改→**重新冒烟**→再冻结→**RZ-0 清场重做**（新改动可能影响数据分布，旧数据作废）。
2. **论文级规模参数**：训练 12–15 条/seed、测试 ≥100 条/seed（A2/A3 × N2/N3 四组合各 ≥25）、120s 基准、**10 seed**（S3 统一基线）；布局随机化泛化层 N_layout ≥6（入门）/10（推荐）、每布局 5 方法 × 2–3 seed（S3.5）；MILUV 外部真实域数据为第三方公开数据，不重生成，仅做适配评估（S3.5b）。
3. **重新生成全部 seed 数据**：主场景 10 seed 全部重新生成；每 seed manifest 含生成器 commit hash、规模参数、随机根 seed、注入统计（ρ/μ/σ 实测）、文件数/字节。
4. **S9 校验 + DQ-1–DQ-4 全量重跑**：对**每一份新数据**逐项校验（GDOP/ρ/μ/σ/可解率/schema/行数 1200+18000/难度梯度/信噪比/分布一致性/样本量充分性），任一不合格 → 该 seed 重生成（P19 可复现保证）。
5. **新旧数据混用禁令（硬约束）**：禁止"部分 seed 新 + 部分 seed 旧"混用；禁止把冒烟 ≥12 条测试数据并入全量测试集（与"测试轨迹重新生成"一致，此处整批化执行）。
6. **重生成完成判定**：全部 seed 通过 S9 + DQ；新数据校验和入 Pre-4；manifest 齐备；decision log 记录重生成时间戳与参数。

**出口**：RZ-1 全部完成并留痕 → 进入全量训练（RZ-2）；任一未过 → 修（数据/参数/生成器）后重生成，**不得用未过校验的数据进入训练**。

#### RZ-2 重训 gate（用新数据从头训练全部单元，旧权重一律禁用）

**目的**：全部模型权重必须用 RZ-1 生成的新数据集**从头训练**（无预训练、无旧权重热启动），保证"权重—数据"对纯净对应。**触发时机**：RZ-1 通过后，全量训练即为 RZ-2 的执行本体。

**动作清单**：
1. **权重初始化（硬约束）**：所有方法同 seed 随机初始化（P32），**禁止加载任何旧权重/预训练权重/迁移初始化**；代码层确认无 `load_state_dict` 指向 archive 或旧路径。
2. **训练管线不变**：训练超参、best-val checkpoint 选择（P33）、精度模式（P19 TF32 统一）、早停标准与冒烟通过时完全一致（code freeze 范围内）。
3. **全量单元**：主场景 **10 seed × 5 方法 = 50 单元**全部用新数据训练；布局随机化层每布局 5 方法 × 2–3 seed（S3.5）；MILUV 用冻结权重做一次性评估（不做训练对比，S3.5b）。
4. **逐单元落盘**：权重/指标/日志/配置 hash/manifest 独立落盘（P39）；运行中监控/断点续跑/NaN 处置按既有流程（P24）。
5. **新旧权重混用禁令（硬约束）**：若发现某单元误用旧权重/旧数据（如断点恢复时加载错路径）→ 该单元作废重跑（断点恢复一致性校验 R-1⑥ 同款机制）。
6. **重训完成判定**：50 单元齐全（G-1）、指标可读（G-2）、无告警残留（G-4）、输出对齐（G-5）。

**出口**：RZ-2 全部单元完成并留痕 → 进入完整性汇总（G-1–G-5）→ 执行合规审计（E-1–E-6）→ 诊断（0-V/D）→ RZ-3 验收；任一单元未过 → 按断点续跑/归因处理，**不得带缺进入验收**。

#### RZ-3 论文级验收 gate（验收只针对"重生成+重训"后的论文级结果）

**目的**：所有验收判定（A-1–A-9、泛化/真实域层判定）**只针对 RZ-0/RZ-1/RZ-2 之后的新数据、新权重结果**；旧结果的验收数字/论文表格草稿一律作废。**触发时机**：全量结果完整性汇总 + 执行合规审计 + 八层诊断完成后。

**动作清单**：
1. **前置 gate 核验（硬约束）**：RZ-0（清场清单）、RZ-1（重生成 manifest + S9/DQ 报告）、RZ-2（重训日志 + G-1–G-5）三 gate 的留痕**全部可查**，任一缺失 → 不得声称"论文级验收"，补齐或重做对应 gate。
2. **完整验收表逐项打勾**：A-1–A-9 全部针对新数据新权重结果（排序/提升 40–62.5%/落窗 LNN 3–4m、EKF 6–8m/C4 ≥整体且 ≤4.5m/C1 2–3.5m 且 ≤整体/P95 拉开/无告警），判据与 Part 0 完全一致。
3. **统计口径核验**：10 seed 配对（每方法 ≥1000 轨迹级样本）、四组合切片、Holm 校正、bootstrap CI——全部基于新数据重跑（P22），**不沿用任何旧统计输出**。
4. **泛化/真实域层判定**：布局随机化层稳定率 + 排序一致性（Kendall τ）、MILUV 域外评估（LOS/NLOS 分段）按 S3.5 判定；②③层不替代①主场景的因子结论，仅并列报告。
5. **验收通过** → 论文表格使用新数据结果；**验收未过** → 走八层诊断 D1–D31 → 失败归因与重跑决策 R-1–R-5（RZ 不替代 R；R 重跑后须**重新核验 RZ-1 数据/ RZ-2 权重对应关系**，避免"重跑单元用了旧数据旧权重"）。
6. **验收报告（论文可复现性附录材料）**：RZ 四 gate 留痕（清场清单/重生成 manifest/重训日志/验收表）整理为附录"数据与执行纯净性核验"，与论文方法节"数据与验证"小节对应。

**出口**：RZ-3 全部通过并留痕 → 论文级验收完成，结果进入论文；任一未过 → 按回查列处理，**不得带病交付**。**预验收符合性自查（提交用户前的最后一道门，硬约束）**：整理论文级结果提交用户验收之前，必须对照本文档目标要求逐项自查——Part 0 合格基准（排序 LNN < LSTM ≤ Transformer < EKF ≤ Robust-EKF、提升 40–62.5%、落窗整体 LNN 3–4m / EKF 6–8m、C4 切片 LNN ≥ 整体且 ≤ 4.5m、P95 拉开）+ 本验收表 A-1–A-9 逐项 + E-1–E-6 审计记录齐全 + 数据/权重纯净（RZ-0–RZ-3 留痕可查）；**全部符合才允许提交用户验收；任一项不符合 → 不得提交，回到对应回查/归因链继续闭环**；提交物必须包含：最新论文级结果（达标项逐项数值）+ 证据链（RZ 清场清单/重生成 manifest/重训日志/审计记录/验收表）——用户只负责对摆出的结果做最终验收裁决，不做中间审批。

### 实验准备（环境/仓库/资源 gate，Pre-1–Pre-6，未过不进 Step 0）

> **为什么需要这一节**：可复现实验的起点不是代码，而是"环境可复现、改动可追溯、数据可校验、资源有预算"。若环境未锁定（换机重跑结果漂移）、改动无日志（跑完不知道哪个版本）、数据无校验和（静默损坏流入统计）、资源无预算（全量投到一半超时），跑前预检与冒烟再严也白搭。本节是**整个流程的第一道门**，置于实现完成清单之前：环境锁定与决策日志是跨机可复现与审稿可追溯的前提（确定性 ML 框架与开放科学 TOP 指南为文献共识），数据校验和与资源预算是防静默事故的工程底线——均有公开文献支撑（含近3年可复现性框架与实验管理研究），正文不标注引用。

- **逐方法独立落盘**：每个「方法 × seed」的训练结果（权重/指标/日志）独立存盘，任一中断只重跑该单元，**不连坐整批**；日志含 git commit + 配置 hash（P39）。
- **周期探针**：**每训练 20 epoch（或每个方法×seed 单元结束时）**记录 loss / 权重范数 / 梯度范数（P24 的持续化）；loss 出现 NaN/Inf、梯度范数突增即**自动止损并告警**，不等到全量结束才发现；探针周期与训练总 epoch 数适配（总 epoch <50 时改为每 10 epoch 一探）。
- **NaN/Inf/梯度爆炸处置出口（fail-stop 优先、可重试其次、可跳过最末）**：①触发告警 → **立即止损**（保存当前 checkpoint + 完整日志），**禁止静默继续**；②归因（RCA）：查超参/lr/数据异常/数值稳定性（P24），写入 decision log；③可修复且修复可验证 → 重跑该单元（重新冒烟若改码 + 回归点 R-3）；④修复后仍复现 NaN/Inf（同一根因 2 次）→ 该「方法×seed」单元**作废**并在 G-1 记录缺单元原因、按断点续跑补跑；⑤若 5 方法中某一方法系统性 NaN（≥3 单元同因）→ 升级查实现（第二层 D5–D8 / I-3），**禁止通过调 lr 反复试探掩盖**（重跑纪律 R-3，防变相 p-hack）。
- **异常类型预案**：OOM/显存溢出 → 降 batch/升精度处理后续跑；单机超时 → 按「方法×seed」分片提交，逐片续跑；数据损坏 → 该 seed 重生成（P19 保证可复现）。**断点恢复一致性校验（硬约束，衔接 R-1⑥）**：任何中断（掉卡/进程被杀/磁盘写满/断电重启）恢复后，**必须校验该单元与断点前的一致性**——同 seed 同配置重跑该单元（或重跑断点前 20 epoch 前段对比 loss/指标），与断点前日志/指标一致（浮点末位差可接受）才可并入统计；不一致（如权重从旧 checkpoint 加载、epoch 计数错位、数据文件版本漂移）→ 该单元作废重跑，**禁止"恢复后结果漂移"混入统计**——checkpoint/restart 语义一致性（恢复后状态与中断前一致、日志与状态持久化可校验）是长时程实验恢复的硬要求（公开文献共识，含近3年 checkpoint 恢复一致性、workflow 恢复语义契约、roll-forward 崩溃恢复研究），正文不标注引用。
- **资源预算确认**：全量（10 seed × **5 方法** × 训练 12–15 条）**在冒烟通过后再投**；冒烟先确认单单元耗时与资源，估算全量总时长；**预算按论文级规模 10 seed 全额核定，不做任何降档（seed ≥8/训练 ≥8/测试 ≥80 类底线一律取消——S3 论文级 10 seed/12–15/≥100 为唯一基线）**；估算显示 GPU 余量不足 → **串行排队执行**（同一 GPU 上逐单元依次跑完，不换卡/不加机/不扩资源），禁止降 seed/降轨迹数；全量必须满额 10 seed × 5 方法 × ≥100 测试轨迹才算论文级完成。
- **中间产物可追溯**：每个单元存配置 hash、seed、完整指标、git commit、数据 manifest（P39），全量结束后可逐行复现。

### 全量结果完整性汇总（全量→跑后诊断 gate，未过不进 0-V1）

> **为什么需要这一节**：跑后诊断（0-V1..D31）的前提是"全量 50 单元结果完整、可信、与数据契约一致"。若少单元/坏文件/指标不可读/告警未清零，直接进诊断会让诊断结论失真（例如少 1 个 seed 的 LNN 恰好是拖后腿的单元，诊断会误判"LNN 非最低"）。此节是全量结束、进入跑后诊断前的**最后一道完整性闸门**。

### 执行合规审计（"是否认真执行"的证明与检测，E-1–E-6，未过不进跑后诊断）

> **为什么需要这一节**：G-1–G-5 只能证明"结果文件齐全"，不能证明"实验是按协议认真执行的"。若存在执行偏差（漏跑单元、改码未重新冒烟、gate 走过场、日志与结果对不上），八层诊断再严谨也会把"执行违规"误判为"方法失败"。执行合规审计用**审计轨迹（audit trail）+ 双重复核 + 抽查复跑**证明执行可信——实验可复现性审计、ML 生命周期溯源、实验追踪的审计用途、"未认真执行"的防舞弊核查（gate 自动化、双重复核、独立复跑、日志异常检测）均为文献共识，均有公开文献支撑（含近3年研究），正文不标注引用。

## Part 3 · 跑后保障：异步+NLOS 下 LNN 非最低 防御与诊断

**总原则**：LNN 非最低 ≠ 方法不行。七成情况是"假象"（评估口径/单 seed 偶然）或"任务压力不足"，两成是"实现/机制未生效"，一成才是真问题。按顺序逐层排查，**前一层不过，不进入下一层**；每层都有明确判定标准。

### 前置：可视化速查（先看图，再算数，0-V1–0-V6）

> 跑后**第一件事不是算 RMSE，而是画图**。坐标系错、航向反、NLOS 偏差被削弱、门控不触发，在图上都是"一眼假"，绕数值则要跑好几层。此层不产生结论，只负责把明显假象筛掉。

### 第零层：RMSE 落窗前置保障（先落窗，再谈排序）

> **为什么需要这一层**：LNN 非最低的相当概率不是"方法不行"，而是"RMSE 整体不在合理窗口"的下游症状——误差过大时所有方法一起高、相对差距被底噪淹没；误差过小时任务无压力、方法无差异。文献机制：位置误差由"测距噪声 × GDOP 几何放大"决定；NLOS 给测距加的是**滤波压不掉的系统性正偏差**；轨迹评估必须先做对齐，否则初始位姿/漂移被永久计入每一帧。**因此：落窗失败先修根因，不进入第一层。**

### 第一层：先排除"假象"（评估口径与偶然性）

> 症状：LNN 均值 RMSE 不是最低，或与 LSTM 差距 <5%。先确认这**不是**评估错误或偶然。

| # | 定位动作 | 判定 / 对策 |
|---|---|---|
| D1 | 核对评估口径：Sim(3) 对齐是否应用？warm-up 前 10s 是否剔除？是否 2D 且世界系？（见预检 P9/P10/P37/P38） | 任一未满足 → 修正后重算，不算失败 |

**不显著结果的正式统计出口（D26–D28 之后、D29–D31 之前的规范判定，方向三核心）**

> **为什么需要这一节**：当主假设（LNN vs EKF 显著优势）不显著时，最常见的错误是"p≥0.05 → 没有差异"或"事后补个功效分析证明样本不够"。近3年统计方法学共识非常明确：**非显著 ≠ 无效应**；**"证据不足"（样本/设计不足以支持结论）与"等效/无差异"（有足够证据证明差距小于预设边界）是两种完全不同的结论**，必须分开；post-hoc power 只重复样本信息、不能证明无效应，**禁止作为解释依据**；TOST 等效性检验与贝叶斯因子（BF）是主张"无差异"的正规工具；同一研究的推断体系必须一致（不能先 frequentist 显著、不显著了又换 Bayesian 救火）——均有公开文献支撑（含近3年统计方法学综述与 TOST/BF 指南），正文不标注引用。

**判定链（按顺序执行，任一环节进入正式出口即停止）**：

1. **预设等效边界（SESOI，实验方案冻结时定，Pre-2 预注册口径）**：在方案冻结时预设**最小有意义效应（SESOI）**——本实验为 LNN vs EKF 相对提升的**实际判定下限 33%（窗口内数学可达下限，见 Part 0）**，等效边界取该值的 ±50%（即相对提升 ±16.5% 内视为"等效/无实际差异"）；SESOI 写入 Pre-2 决策日志与预注册声明，**事后不可更改**（预设判据先于数据、避免事后解释漂移是统计规范，公开文献共识）。
2. **p 值 + 效应量 + CI 联合报告**（D26/D27/D28 已要求）：校正后 p≥0.05 时，**如实报告效应量（Cohen's d / 相对提升）与 95%CI**，不单独解释 p 值；CI 上界仍小于 SESOI → 支持"差距小于实际意义边界"的证据；CI 过宽（含 0 且含 SESOI 内与外）→ **证据不足**，加 seed/轨迹（预算内，**只增不减：规模恒 ≥ 论文级 10 seed × ≥100 条/seed，P22 扩样路径——不存在"降档/收窄"出口，S3 硬约束**）。
3. **主张"无差异/等效"必须补 TOST**：若要写"LNN 与 X 等效/无实际差异"，必须做 **TOST 等效性检验**（两组单侧检验，等效边界 = 步骤 1 的 SESOI，90% CI 判定），TOST p<0.05 → 可主张"等效"；TOST 不显著 → 只能写"证据不足"。
4. **可选贝叶斯因子（BF）交叉验证**：报告 BF01（支持 H0 的强度）作补充证据（BF01>3 弱支持、>10 强支持），**与 frequentist 结论并列报告、不互相替代**；禁止"先 frequentist、不显著再补 BF 救火"的推断体系切换（推断一致性是规范，公开文献共识）。
5. **多重比较校正已含**：五方法 10 对 Wilcoxon 已做 Holm-Bonferroni（P22），TOST/BF 若按对执行同样按 10 对校正口径报告。
6. **出口归属**：判定"证据不足"→ 按 D26 加样本或按 R-1④统计性失败处理；判定"等效/无差异"（TOST/BF 支持）→ 进入 D29/D30 叙事（尾部/条件性优势）或 R 系列（方法性失败③，诚实负发现）——**"等效"是有证据的负发现，不是失败**。

**期刊图表规范覆盖层（覆盖八成以上目标期刊的格式/统计兼容方案）**：

> **为什么需要这一层**：图表交付清单（T/F）解决"画什么、什么口径"；本层解决"**投到八成以上目标期刊都不会因格式/统计呈现被拒**"。定位/传感/UWB 类期刊的图表与统计要求高度同构（审稿人看重：误差分布可见、统计量可核、单位/坐标轴自明、图注自足、颜色可读），期刊间差异主要在排版细节而非科学内容。本层给出**高兼容默认方案 + 同类期刊抽样兼容矩阵**，让一套图表在不重画的前提下覆盖 ≥80% 的投稿目标。

**目标期刊集合（按本实验领域分层抽样，覆盖 ≥80% 兼容性判断）**：
- **定位/传感器类（IEEE T-ITS / IEEE IoT-J / IEEE Sensors J / IEEE TIM / IEEE TAES / IEEE TMC / IEEE TWC）**：轨迹误差图 + CDF + 箱线是标配；要求图注完整自足、变量符号统一、坐标轴带单位；表须报 mean±std + 显著标记（如 *p<0.05, **p<0.01, Holm 校正标注）；常见不接收"只有均值条形图无分布信息"的主结果呈现。
- **机器人与融合类（IEEE RA-L / IEEE TRO / IROS/ICRA / Robotics and Autonomous Systems）**：同轨迹叠加 + 分段误差 + 泛化验证是加分项；强调"真实/仿真数据分离声明"与"独立重复次数"（seed 数写在实验设置）；对消融表要求每行有统计支撑或显式声明非显著。
- **信号处理类（IEEE TSP / Signal Processing / IEEE SPL / Digital Signal Processing）**：偏重理论呈现（CRLB/GDOP 分析图、误差构成分解）；ANOVA/CI 是加分；对坐标单位与几何设置描述要求严格。
- **通用人工智能类（Neural Networks / Neurocomputing / ESWA / Information Fusion / IEEE TNNLS）**：强调与 SOTA 的公平对比表 + 显著性 + 效应量；激活/注意力可视化（机制证据）是审稿加分项；附录可复现性说明加分。
- **测绘/室内定位专门类（IPIN 会议 / Indoor Positioning and Indoor Navigation / GPS Solutions / Journal of Navigation）**：P50/P95/CDF/分场景分解是行业惯例；对"测试轨迹数/环境数/独立实验数"要求明示；CDF 到 P99 常见。

**高兼容默认方案（按此产图产表，可直接满足 ≥80% 目标期刊的形式要求；差异化排版在投稿时用期刊模板微调即可，不重画数据）**：
- **表默认**：三线表或期刊模板表；每表必带自足标题（含实验条件一句话）；数值格统一 `mean±std`（单位在表头）；显著性用 `*`/`†` 上标 + 表注说明校正方法（Holm-Bonferroni）；Δ/百分比列带绝对差与 95%CI（P36）；表注声明分析单位（轨迹级）与数据层（①/②/③）。
- **图默认**：300 dpi 以上、TIFF/PDF 矢量或高分辨率位图；字号 ≥ 7pt、图内文字可缩放不糊；坐标轴带单位（m/s/Hz/%）；图例放图内或图注首句；**配色用色盲安全调色板**（Okabe-Ito / colorblind-safe 序列，满足 IEEE 与一般期刊可读性）；主结果必须含分布（CDF 或箱线），不只均值条。
- **统计呈现默认**：凡"显著"必有 p（校正后）+ 效应量；CI 未校正必声明；seed 数、轨迹级样本数、独立实验数在实验设置或表注明示。
- **图注自足默认**：每张图注含——数据来自哪一层（①主场景/②布局随机化/③MILUV）、误差口径（轨迹级/帧级）、样本量（N 轨迹）、显著性标注方法、单位。
- **附录默认**：T-8（可复现性核验表）进附录或补充材料；RZ 留痕摘要一句话进方法节。

**验收分级与降级出口（消除"必须全过"与 D31"承认局限"的矛盾）**：

> 验收表 A-1–A-9 的"每一项都必须通过"指**在完整验收路径下**逐项回查修通；但当跑后诊断第八层 D31 已把工程/统计/机制全部排除、确认真实局限时，允许**降级交付**——不造假、不硬撑、不卡死。三条出口按证据强度分级：

| 级别 | 触发条件 | 出口动作 |
|---|---|---|
| **完整验收** | A-1–A-9 全部通过（含 A-2 提升 40–62.5%、A-3 落窗、A-6 四组合/C4 卖点） | 结果进论文表格，按 Part 0 口径报告 |
| **条件验收** | A-3/A-6 落窗与 C4 卖点通过，但 A-2 提升 <40%（机制生效但卖点未达预期） | 按 D29/D30 叙事调整：报告 P95/尾部/条件性优势（C4 切片领先可作卖点），A-2 未达上限如实披露，走"尾部/条件性"叙事，不虚报均值 |
| **降级交付** | 跑后诊断八层全过（D31）、**R-1–R-5 失败归因与重跑决策已完成（归因分类确认**方法性失败③**或**数据性失败⑤**（⑥硬件/环境性失败已按 R-1⑥ 记录处置完毕、不进入降级交付）、RCA 记录、重跑纪律遵守≤2 轮）**，确认 LNN 无任何可归因优势（方法性）**或数据集无法支撑研究问题（数据性）**，且 A-3/A-6 落窗与 C4 卖点未站住 | 如实报告负发现：**方法性失败** → "LNN 在异步+高 NLOS 下与基线无显著优势"的诚实结论；**数据性失败** → "当前数据不支持该研究问题/结论外推范围"的诚实声明（附 DQ 证据：难度梯度/信噪比/样本量）；调整选题叙事或转向机制分析（激活对齐/误差构成）作为贡献点；**不伪造结果、不删除失败组合、不换口径重算** |

**判定顺序**：完整验收 → 任一未过按回查列修 → 修不通但诊断确认机制生效/压力足够 → 条件验收；八层全过仍无优势 → 降级交付。三种级别都**必须先通过 G-1–G-5（全量结果完整性汇总）与 0-V1..0-V6（可视化速查）**，确保评估口径正确、结果完整可信——**此处"降级"仅指"结论声明强度"分级（完整/条件/诚实负发现），实验规模恒为论文级（10 seed × 5 方法 × ≥100 测试轨迹/seed），任何一级都不允许以缩减规模交付（S3 规模不可降级硬约束）**；降级交付的是"结论"，不是"数据质量"。

### fail-safe 判别总入口（认真执行仍失败 / 疑似未认真执行 / 数据集问题的三问分流；R 系列的正式入口，与消融手册一致）

> **什么时候走到这里**：全量结果完整性 G-1–G-5 与执行合规审计 E-1–E-6 通过后，"认真执行了、异步高NLOS实验仍未达预期"（主线排序 LNN 非最低 / 落窗失败 / 提升 <40%），且第零层与八层诊断 D1–D31 的工程回查链已逐层排除。此时按三问分流，**禁止跳过"认真执行审计"直接判"方法不行"，也禁止把"数据集问题"误报为"方法性失败"**。

**第一问：我真的认真执行了吗？（执行可信性 audit）**
- 查 E-1–E-6：decision log（Pre-2）时间戳链是否完整无倒挂、gate 通过记录（Pre-1–Pre-6 / I-1–I-5 / S9 / DQ-1–DQ-4 / 冒烟 / code freeze / G-1–G-5）是否逐项可追溯、统计是否双重复核（E-3）、是否有 ≥2 单元抽查复跑（E-4）、告警是否清零且无吞异常（E-5）。
- 任一未过 → **②执行性失败（未认真执行，R-1②）**：先补证据或重跑对应 gate，**禁止把"执行违规/未认真执行"当"方法失败"进归因**（E-6）。

**第二问：是不是数据集本身有问题？（数据适配性 audit）**
- 查 DQ-1–DQ-4 + S9 + E-4：难度梯度是否成立（C1 vs C4 实测差 vs 误差预算理论估算）、信噪比/可区分度是否足够（N2/N3 μ vs LOS 噪声×GDOP 传播）、训练/测试分布是否一致、样本量是否支撑功效（P22）、数据校验和是否一致（Pre-4/E-4 抽查复跑指向）。
- 任一命中 → **⑤数据性失败（数据集有问题，R-1⑤）**：先修数据（重生成该 seed / 调轨迹设计 / 走协议变更），修不通 → 诚实声明"当前数据不支持该研究问题/该结论外推范围"（附 DQ 证据），**数据性失败 ≠ 方法性失败**（R-4/R-5）。

**第三问：是工程 bug 还是方法真不行？（归因分流）**
- 走八层诊断与失败分流逐层回查（D1–D4 假象/偶然 → D5–D8 架构/实现 → D9–D13 训练公平 → D14–D17 数据压力 → D18–D21 门控激活 → D22–D25 EKF 公平 → D26–D28 显著性）；任一命中 → **①实现性失败**（R-1①）：修码/修数据后按 R-3 重跑（改码须重新冒烟 + 回归点复核）。
- 全部排除 → 进入 **R-1 归因分类**：③方法性失败（机制性核验先行：压力是否真实、机制是否未生效——先查 D14–D17 压力与 D18–D21 激活，后判方法局限）、④统计性失败（功效不足，加 seed/轨迹）、⑥硬件/环境性失败（断点续跑 + 恢复一致性校验 + 环境日志留痕，影响 >25% 单元 → 该批数据作废重生成）→ R-2 RCA → R-3 重跑纪律（≤2 轮）→ R-4 诚实报告 → R-5 兜底出口。

**铁律**：没有 RCA 记录不得重跑；同一失败最多重跑 2 轮；**严禁"为让 LNN 最低而重跑 / 选择性重跑有利单元 / 挑 seed / 换口径重算"**（p-hacking，R-3）；"认真执行仍失败"的出口是**诚实分级交付**（负发现 / 机制分析 / 条件性优势也是可发表贡献，R-4/R-5），不是伪造、不是硬撑、不是无限重跑。

### fail-safe 补救操作手册（审计发现"未认真执行/执行性偏差"后的逐项补救动作）

> **什么时候用本节**：fail-safe 第一问（我真的认真执行了吗）命中——E-1–E-6 任一未过 → ②执行性失败（R-1②），或第三问回查中发现工程实现偏差。本节给出"未认真执行"的**逐项补救动作**。三条总纪律（硬约束）：**①补证据 ≠ 重跑，重跑 ≠ 翻篇**——证据缺失先补证据（能补则补），补不了的才重跑；**②补救动作与 RCA（R-2）一一对应**，无 RCA 记录的补救视为无效补救；**③补救是恢复可信，不是挑选有利结果**——禁止借"补救"选择性重跑有利单元、禁止借补证据悄悄换口径（p-hacking，R-3 同款禁令）。

| P5 | **告警被静默清除/吞异常（E-5）** | ① 从日志恢复被清除的告警记录；② 对每一条告警补处理记录（原因/处置/影响单元）；③ 受影响的单元（NaN/梯度爆炸/OOM 发生但未按 P24 处置的）按 P24 处置出口重跑 | E-5 告警清零有据可查（G-4） | 告警影响单元已混入统计 → 该单元作废重跑 |
| P6 | **gate 走过场（Pre/I/S9/DQ/冒烟任一证据造假或缺失）** | ① 该 gate 按对应清单**完整重做**（不做局部修补）；② 重做留痕（时间戳 + 操作人 + 结果）；③ 走查为何会走过场（流程漏洞 → 补自动化断言/双人确认，写入 decision log） | E-2：gate 通过证据完整 | 该 gate 下游的所有产物作废重跑（如冒烟 gate 重做 → 冒烟数据作废、重新冒烟） |
| P7 | **code freeze 后改码未重新冒烟** | ① 解冻 → 记录改动（decision log + git commit）；② **重新冒烟**（改动可能影响数据分布 → 若改的是数据生成器，须同时 **RZ-0 清场重做**）；③ 冒烟通过 → 重新冻结 | 冒烟 gate ①/② + RZ-0/RZ-1 留痕 | 数据生成器改动 → RZ-1 全量重生成 + RZ-2 重训；仅训练/评估代码改动 → 已跑单元按影响范围作废重跑 |
| P8 | **旧权重热启动/续训/load 错路径（RZ-2 违规）** | ① 代码层排查所有 `load_state_dict`/checkpoint 加载路径，确认不指向 archive/旧权重；② 误用旧权重的单元**作废重跑**（同 seed 随机初始化，P32）；③ 若为断点恢复错路径 → 按断点恢复一致性校验（R-1⑥）重跑该单元前段对比 | RZ-2 重训留痕 + G-1 单元齐全 | 误用旧权重的全部单元作废重跑，不连坐整批 |
| P9 | **数据混用（冒烟数据并入全量 / 部分 seed 新旧混用）** | ① 按 RZ-1 禁令核查全量数据来源（manifest + 校验和 Pre-4）；② 混用命中 → **RZ-1 全量重生成**（10 seed 全部重新生成 + S9/DQ 全量重跑）；③ 补数据来源审计记录 | RZ-1 留痕 + S9/DQ 报告 + G-3 配置-数据交叉 | RZ-1 重生成后 → RZ-2 全部单元重训 |
| P10 | **统计口径漂移（换检验/换分析单位/换判据未登记）** | ① 按 Pre-2 三级分类定性：**分析变更**（换检验/分析单位/判据）→ 写入 decision log 并在论文报告为偏离预设；**协议变更**（改档位/场景/方法定义）→ 走正式协议变更流程；**执行偏差** → 记 execution deviation 表；② 口径漂移涉及的已出统计 → 按恢复后的统一口径重算 | Pre-2 变更登记 + 统计口径全局唯一声明复核 | 协议变更 → 受影响实验重跑（更新协议后）；分析变更 → 重算统计（不重训） |

**补救执行规范（每项补救通用五步）**：① **RCA 记录**（R-2 模板：现象→复现→假设→证据→结论，写入 decision log）；② **执行补救动作**（按上表 P1–P10）；③ **回归点复核**（改码→重新冒烟；换数据→S9+DQ+G-3；统计口径→统计脚本冒烟验证 gate ①；任何重跑→G-1–G-5 完整性 + E-1–E-6 审计重跑，产生新 audit trail）；④ **decision log + git commit 更新**（时间戳链与补救动作一一对应）；⑤ **回到对应 gate 重跑**——补救完成后从被破坏的 gate 之后重新走流程，**禁止补救后直接跳进诊断/验收**。

**补救边界（防补救变成第二次作弊）**：补救只修复"证据/执行/实现"缺陷，**不改变实验设计、不调判据、不挑选单元**；补救后仍失败的单元 → 回到 fail-safe 第二/三问（数据集问题 → R-1⑤；工程 bug 还是方法不行 → R-1①③④⑥），按 R 系列正规出口处理，补救轮次计入 R-3 重跑纪律（同一失败最多重跑 2 轮，2 轮后仍失败 → R-5 兜底出口）。

### 失败归因与重跑决策（"认真执行仍失败"的兜底，R-1–R-5）

> **为什么需要这一节**：前面的 gate 与八层诊断把"执行违规/评估口径/实现错误"全部排除后，仍可能面对"认真执行了、方法确实没达到预期"。此时要回答两个问题：**这是哪一类失败？该不该重跑？**——失败不归因就重跑=盲跑（无限重跑=变相 p-hacking），失败不分类就接受=把"统计口径错/实现错"误当"方法局限"。失败归因分类、根因分析（RCA）、fail-stop 重跑纪律、负结果诚实报告、预设判据与事后解释区分、p-hacking 防范——均为文献共识，均有公开文献支撑（含近3年研究），正文不标注引用。

| # | 步骤 | 内容 | 判定 / 处置 |
|---|---|---|---|
| R-1 | **失败归因分类** | 把"未达预期"先归类：**①实现性失败**（代码/数据/口径 bug，E-1–E-6/P 系列可指向）；**②执行性失败**（gate 未过/审计未过，E 系列）；**③方法性失败**（八层诊断排除①②④⑤⑥后，机制/优势确不存在）；**④统计性失败**（功效不足/样本量少，D26–D28）；**⑤数据性失败（数据集不合适——数据不支撑研究问题）**（DQ-1–DQ-4 指向：难度梯度不足无信息量 / 信噪比太低方法不可区分 / 分布不可学 / 样本量不足以支撑结论；含缺失率超限、标签污染、泄漏——数据审计 DQ/E-4 可指向）；**⑥硬件/环境性失败（硬件故障与环境动态，与"方法失败"分开记账）**（GPU 掉卡/OOM 未恢复、磁盘写满、进程被杀、UWB 锚点掉线/标签电源中断、网络中断、环境动态（人员走动/多径随时间变化/温漂/电磁干扰）导致数据与场景图不符——运行监控与断点续跑记录可指向；**恢复后必须校验该单元与断点前的一致性**（同 seed 同配置重跑该单元或前段对比，指标/日志一致才可并入统计，防止"恢复后结果漂移"混入——checkpoint/restart 语义一致性是长时程实验恢复的硬要求，公开文献共识，含近3年断点恢复一致性研究） | ①②③④⑤⑥ 六类处置完全不同：①回实现层修；②回 gate 补；③走降级交付；④加 seed/轨迹（预算内）；**⑤先修数据（重生成/调轨迹设计/走协议变更），修不通 → 诚实声明"当前数据不支持该研究问题或结论外推范围"（数据性失败 ≠ 方法性失败），缩小声明范围或转机制分析（R-5），不得把数据性失败当作方法性失败报告**；**⑥按硬件/环境事件记录：断点续跑该单元 + 恢复后一致性校验（重跑前段对比指标/日志，一致才并入统计）+ 环境日志留痕（时间戳标注，decision log）；若环境动态影响范围 >25% 单元 → 该批数据作废重生成（S1 场景图与 manifest 不符），不得把硬件/环境性失败当作方法性失败报告** |
| R-2 | **根因分析（RCA）记录** | 对每类失败写正式 RCA：现象 → 复现步骤 → 假设 → 证据（日志/指标/审计轨迹）→ 结论；写入 decision log（Pre-2） | 无 RCA 记录不得重跑；RCA 结论是"重跑 or 接受"的唯一依据 |
| R-3 | **重跑决策纪律（fail-stop）** | 允许重跑仅限：①RCA 指向实现/执行/统计口径问题且修复可验证；②预设判据内（如补 seed/轨迹到设计值）。**禁止**：无 RCA 重跑、为达到 40–62.5% 窗口而重跑（变相调参）、选择性重跑"看起来有利"的单元。**流程回归点（重跑成功后必须重验的 gate，缺一不可）**：①改码/改配置 → 重新冒烟（冒烟→全量 gate ②）；②换数据 → **S9 校验 + DQ-1–DQ-4 适配性复核** + G-3 配置-数据交叉；③统计口径变更 → 统计脚本冒烟验证（gate ①）；④任何重跑单元 → 重新跑 G-1–G-5 完整性汇总 + E-1–E-6 审计（重跑产生新 audit trail，与 decision log 时间戳链一致）；⑤重跑后指标变化 >5% 相对差 → 记入 decision log 并说明原因（防重跑悄悄改变结论——aggregate 可复现不能替代实例级可复现，公开文献共识，含近3年审计与可复现研究） | 每次重跑更新 decision log + git commit + 重新冒烟（若改码）+ 重新审计；**同一失败最多重跑 2 轮，2 轮后仍失败 → 整理最新论文级结果与完整证据链提交用户验收裁决（不得以"已到 2 轮"自行收工或自行降级），不得无限重跑** |
| R-4 | **诚实报告规范（负结果）** | 若最终为方法性失败**或数据性失败**：报告预注册口径（方案冻结时预设的成功/失败判据，见 Pre-2）、区分"预设分析"与"事后解释"、如实报告效应量/CI/负结果；不 p-hack（不删除失败组合、不换口径重算、不挑 seed）；**数据性失败（⑤）报告口径**：明确声明"当前数据不支持该研究问题/不支持该结论外推范围"（数据集限制声明，而非方法无效），给出 DQ 证据（难度梯度/信噪比/样本量）与改善路径（重生成/加样本/调档位） | 论文按 D31/D29 口径诚实表述：负结果也是可发表贡献（机制分析/负发现），前提是证据链完整（E 系列 + G 系列 + DQ 系列） |
| R-5 | **兜底出口确认** | 八层诊断全过 + RCA 完成 + 重跑纪律遵守（≤2 轮）后仍无优势 → 正式确认**降级交付**：诚实负发现（LNN 在异步+高 NLOS 下与基线无显著优势），贡献点转为机制分析（激活对齐/误差构成）或缩小声明范围（条件性优势 D30） | 不造假、不硬撑、不卡死；降级交付的前提是**数据与执行可信**（E-1–E-6 已过），降级的是"结论强度"而非"数据质量"；**降级交付不得自行生效：须整理最新论文级结果与完整证据链（E-1–E-6 审计记录 + 八层诊断结论 + RCA + 重跑记录）提交用户验收裁决，用户裁决同意后（decision log 记录）方可生效——未提交用户验收 = 不得收工，回到归因链继续闭环** |
