主线 A：LNN RMSE 显著低于误差预算上界（= 纯 UWB 三边测量 RMSE），无 >10m 爆炸行。 主线 B：LNN 为四方法最低，且与最佳基线配对 Wilcoxon（Holm 校正后）显著。

0. 判定契约（code freeze 前落盘；pilot 校准项冻结，正式实验开始后禁止修改）
字段	值/方法
error_budget_upper_m	纯 UWB 三边测量 RMSE（4 锚测距解算，不融合；同批测试轨迹、同时间戳、warm-up 剔除后、2D 轨迹级）
error_budget_check	每条测试轨迹算 RMSE，LNN vs 上界单侧配对检验
error_budget_alpha	0.05
error_budget_unit	trajectory-level
noise_level_m	同方法跨 seed 轨迹级 RMSE 的合并标准差（pooled SD）；pilot 估定写 manifest 并冻结；用于 comparison_weak / borderline 判定
primary_method	LNN
primary_comparison_set	[LNN, LSTM, Transformer, EKF]
primary_metric	2D_RMSE（主判定只用它）
secondary_metric	3D_RMSE（辅助报告）
m_axis_fixed	M1
diag_pair	(A2N2, A3N3)；运行期断言各 ≥250 轨迹级样本
holm_family_size	6
sesoi_delta_rmse_m	SESOI = 相对提升 15%（下限）；等效边界 = SESOI × (1±50%) = 7.5%–22.5%；90% CI 完全落在边界内 → 等效；补 sesoi_absolute_m
advantage_m	优势 = LNN 与次低者（按平均轨迹级 RMSE 均值排名第二）的平均轨迹级 RMSE 之差
best_baseline	除 LNN 外按全部轨迹级 RMSE 均值排名最低者；排名表写 manifest
lr_search_space	LNN = 1e-4–2e-2（覆盖 LTC 原文 0.001–0.02）；LSTM/Transformer = 1e-4–1e-3；分方法写 manifest
mainline_a_decision / mainline_b_decision	pass / fail / borderline → manifest
pilot 与冻结规则：pilot 必须在正式训练前完成；noise_level_m、sesoi_delta_rmse_m、sesoi_absolute_m、advantage_m 由 pilot 数据校准后写入 manifest 并冻结；正式实验开始后不得再改。

主线 B 三段判定（三段全过才 pass，否则输出卡在哪一段）：

段 1：LNN 按均值排名为四方法最低；若最低但 advantage_m < noise_level_m → mainline_b_borderline=1，不直接 pass
段 2：LNN vs 最佳基线（按均值排名除 LNN 外最低者）配对 Wilcoxon，Holm 校正后 p < 0.05
段 3：效应量 + 95% BCa CI 不跨 0

[5] 模型架构
LSTM/Transformer 与 LNN 共享完全相同 4 个头，只换骨干
液态骨干：连续时间循环单元，状态方程 ẋ=f(x,I(t),θ) 按实际时间间隔离散化（非固定步长）；LTC 或 CfC 二选一写 manifest（liquid_cell_type）
τ 输入依赖可学习量，范围 1.0–20.0；tau_range_assert、liquid_tau_std_assert（std>0 冒烟断言）；tau_std_manifest：训练后 τ 的 std 写 manifest，作为液态骨干未退化证据
运行期断言禁止退化为固定时间常数 LSTM 变体
risk 头双通道监督：nl_flag 软标签 BCE（平滑 0.1）+ UWB 残差滑动窗口自监督一致性（秩相关 ≥0.3）；自监督一致性为训练损失项；训练后脚本检查实际秩相关 ≥0.3，未达标标记 risk_weak 写 manifest
risk_loss_coupling_assert：risk 输出与损失耦合，禁止 detach/解耦
协方差门控：R_uwb_eff = R_uwb × (1+α·r)，α=10 写 cov_gate_alpha；cov_gate_monotonic_assert（r↑→R_eff↑）；禁止 risk 直接乘残差
Δt 序列分路计算，经可学习时间编码层（正弦/相对二选一，写 ts_encoding）拼接进骨干；ts_detach_assert（时间偏移 detach，时间间隔参与前向）
CIR 特征与 range 同帧对齐（N×3）；cir_features: on
baseline_postprocess（none/de-drift）统一设置写 manifest
EKF 基线：紧耦合（输入契约同模型）；固定协议 R/Q；观测按到达序排队；新息 3σ 拒斥；缺失段 skip 计数写 ekf_innov_stats；条件数 ≤1e8、Cholesky 正定；更新顺序固定 ekf_update_order

[10] 统计报告与判定链
轨迹级分析单位（每 seed 每轨迹一个 RMSE；每方法 ≥1000 样本、四组合每组合 ≥250、diag_pair 各 ≥250）

脚本输出：离群计数与离群比例（P95 外），不自动剔除

13. 五道诊断门禁（写 manifest + 诊断输出）
预训练门禁（三分支）：1 seed 冒烟后，检查 LNN 验证集轨迹级 RMSE vs 最佳基线——低于且差距 ≥ noise_level_m → 通过，进全量；低于但差距 < noise_level_m → pretrain_weak=1，仍进全量但训练中门禁加密监控；未低于但 |差距| < noise_level_m → pretrain_weak=1，同上；未低于且差距 ≥ noise_level_m → 先诊断，不进全量。失败输出：LNN vs 最佳基线逐组合、逐轨迹、逐时间段差距表，写 results/diagnosis
训练中门禁：每 seed 训练后，验证集 LNN vs 最佳基线差距写 manifest；LNN 未最低 → mainline_b_risk=high。失败输出：每 seed 验证集曲线、最佳基线 vs LNN 差距曲线，写 manifest
统计前门禁：全量评估后先算轨迹级 RMSE 均值最低者；不是 LNN → 直接输出失败诊断，统计脚本仍输出全部比较、不跳过。失败输出：轨迹级 RMSE 最低者排名表，写 manifest
误差预算门禁：LNN 轨迹级 RMSE vs error_budget_upper_m → mainline_a_decision。失败输出：LNN 轨迹级 RMSE 与预算上界分布对比，写 results
方法对比门禁：LNN vs 各方法 Δ 写 manifest；与最佳基线差距 < noise_level_m → comparison_weak=1，并输出该基线在哪些组合/轨迹/时间段与 LNN 接近（定位表写 manifest）
