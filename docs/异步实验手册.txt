# 异步实验·执行手册

## 0 · 执行总纲（先读这个，其余全是细则）

### 手册目标（最终检查只看这个）

**主线 A（防 RMSE 整体过大）**：full/LNN RMSE 显著低于误差预算上界，无 >10m 爆炸行。
**主线 B（防 full/LNN 非最低）**：full/LNN RMSE 必须为全部变体/方法中最低，配对检验（Wilcoxon）显著。
数据/代码/结果可追溯（manifest + git commit + 验收留痕）。核验通过后**最终只看目标是否达成，不看流程勾选**。

\[1]五轴档位协议全文见 档位协议条款， **定位实现口径（本手册自包含定义，与同机另一实验体系共用同一套口径，两实验分别按各自协议文件执行档位）**： **紧耦合** ——模型输入含 UWB 原始 range 残差（N×4）+ IMU 高频段（150Hz 原生聚合）+ VIO 相对位姿 + 时间戳四类，不含锚点坐标/几何标签

\[2]**数据口径**——双速率契约（UWB/VIO/gt 对齐 10Hz 公共轴，IMU 保留 150Hz 原生不降采样）

\[3]重采样统一最近邻（禁插值抹平 NLOS 跳变）；归一化统计量只用训练集；TF32 精度全方法统一。三条约束各自独立落实并留痕：① 重采样函数单测（最近邻对齐、无插值路径可走）；② 归一化统计量计算脚本断言"仅读训练集，测试集一律用训练集统计量变换"；③ TF32 开关显式设置（`torch.backends.cuda.matmul.allow_tf32` / `torch.backends.cudnn.allow_tf32`）写入 manifest。

\[6]档位协议条款 · V 轴 —— 视觉退化\*\*（视觉里程计（VIO）质量退化。）

|V 档|名称|具体数值|
|-|-|-|
|V0|健康|特征 >50/frame；增量噪声 σ=0.01–0.03 m/步；帧有效 100%；无间隙|
|V1|黑屏|视觉完全失效：增量在但置零（=0），scaling→0；每序列 1–2 次，单次 0.5–2 s，占轨迹 5–10%|
|V2|特征丢失|特征 10–20/frame；增量噪声放大 5×（σ→0.05–0.15 m/步）；占轨迹 20–40%，连续段 1–3 s；scaling→0.3–0.7|
|V3|关键帧中断|增量缺失（质量触发，非时间戳缺失）；每序列 2–4 次，间隙 0.5–3 s，占轨迹 10–20%；恢复后重定位跳变 0.3–1 m|
|**A 轴丢帧** = 数据不在（时间戳级缺失）|||
|**V1** = 数据在但置零|||
|**V2** = 数据在但变糙（σ×5）|||
|**V3** = 数据不在（质量触发）+ 恢复跳变|||

\[272]**数据生成管线确定性快照（硬约束，npz 可复现）** ——数据生成管线输出确定性快照：同一 rand_root + 同一协议档位下，两次运行生成的数据 npz 必须逐字节一致（禁止时间戳/哈希/进程号混入生成路径）；生成器版本号写入 npz 元数据与 manifest（gen_version），版本不一致的数据禁止混用。验证方法（自测留痕）：冒烟同根跑两遍对比 npz md5；单测断言 npz 元数据含 gen_version。

\[273]**时间戳特征端到端实现规格（硬约束，异步信息真的进模型）** ——模型对异步的处理不允许只停留在"输入含时间戳字段"：时间戳差值特征（Δt 序列：当前帧时刻 − 上一帧时刻，UWB/IMU/VIO 各路分别计算）经可学习时间编码层（正弦位置编码 或 相对时间编码 二选一，写入 manifest ts_encoding）后与对应源特征拼接进入骨干；时间偏移量不参与梯度更新（detach），禁止模型通过学习注入偏移的固定值在测试时作弊。验证方法（自测留痕）：冒烟打印 Δt 特征非零且梯度正常流动（各时间编码层参数更新）；单测构造等间隔序列核对编码层输出形状。

\[274]**CIR/信道特征输入工程（可选增强，开关化）** ——在 UWB range 之外提供信道冲激响应统计特征（首径幅度、峰值幅度、能量集中度/延迟扩展），作为 risk 头附加输入通道（增强 NLOS 可识别性）；实现为可开关项（manifest cir_features: on/off），on 时数据生成器在 npz 中输出 CIR 特征（N×3，与 range 同帧对齐），校验脚本断言形状与取值区间（幅度 ∈ [0,1]、延迟扩展 ≥0），单测用构造的 LOS/NLOS 两段 CIR 核对特征计算正确性。验证方法（自测留痕）：冒烟打印 cir_features 开关状态与特征统计量。

\[275]**不确定性量化输出与覆盖率校准（硬约束，预测置信要可靠）** ——模型在定位输出之外输出预测协方差（2×2 位置协方差 Σ_xy），评估脚本按预测协方差构造 50%/90% 预测椭圆，统计名义覆盖率 vs 实际覆盖率（真实位置落在椭圆内的比例），偏差超阈值（|实际−名义| > 5%）→ 告警并写入 manifest cov_actual；单测用已知协方差的合成数据核对覆盖率计算（正态分布 1σ=68.3% 基准）。验证方法（自测留痕）：冒烟打印 cov_actual 非空且偏差带；单测断言合成数据的覆盖率接近名义值。

\[276]**协方差门控数值实现（risk→膨胀系数映射，硬约束）** ——risk 输出 r∈(0,1) 通过单调映射调制 UWB 量测协方差：R_uwb_eff = R_uwb × (1 + α·r)，α 为写死的常数（默认 10，写入 manifest cov_gate_alpha）；门控必须单调（r 增大 → 膨胀系数增大，冒烟断言在 r 采样网格上验证）；禁止把 risk 直接乘到残差上（防梯度消失与不可解释），只允许作用在协方差/权重层面。验证方法（自测留痕）：单测构造 r=[0,0.5,1] 验证 R_uwb_eff 单调递增；冒烟打印 cov_gate_alpha 生效。

\[277]**敏感性扫描自动化脚本（代码化，防手跑遗漏）** ——敏感性扫描（A 轴注入方式、N 轴档位参数 ±20%、risk 监督权重等维度）由自动化脚本执行：扫描脚本自动遍历扫描网格，每档独立跑评估并输出 RMSE/Δ 到 results/sensitivity 表格（含档位标签列、参数值列、指标列），与主实验 checkpoint 分离管理（不同输出目录，禁止污染主实验产物）；扫描结果写入 manifest sensitivity_summary。验证方法（自测留痕）：冒烟断言扫描表非空且含档位标签列；单测用 2×2 最小网格验证遍历完整。

\[278]**轨迹多样性自动校验（硬约束，回补主实验：测试集代表性）** ——统计脚本按轨迹输出方位角直方图（八方向差 ≤20% 断言）与速度分布（0.5–1.5m/s 全区间覆盖、占比与训练一致断言），结果写入 manifest traj_diversity；目的：测试轨迹集须有可声明的多样性，否则整体指标被少数高难度轨迹主导、LNN 对比结论被单条轨迹绑架。验证方法（自测留痕）：冒烟打印多样性统计；单测构造已知分布验证断言触发。

\[279]**序列相似度泄漏检查脚本（硬约束，回补主实验：防跨集形态泄漏）** ——实现 DTW/形状特征距离计算脚本，训练/验证/测试序列两两检查，归一化相似度超阈值（DTW<0.1）的两条序列不得分属训练与测试；结果写入 manifest sim_leak_check。验证方法（自测留痕）：单测用构造的相似序列对验证拦截；冒烟打印检查矩阵。
