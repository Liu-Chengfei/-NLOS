# audit-report-writer

## 1. 使用场景
- 输出阶段性审计、修复总结、交接说明时。
- 需要分离源码、实验产物、临时缓存、过程台账时。

## 2. 不适用场景
- 不用于决定修什么，也不替代真实验证。
- 不删除未获授权的 repo-tracked 文件。

## 3. 输入要求
- 已改文件、未改高风险文件、验证记录、协议触碰情况。
- 产物根目录、源码白名单、允许保留或删除的范围。

## 4. 输出格式
- `改了什么 / 没改什么 / 验了什么 / 是否触碰科学协议 / 剩余风险`。
- 交付清理时补充：`保留项 / 清理项 / 未动高风险项 / 理由`。

## 5. 决策顺序
1. 先列已改文件。
2. 再列未改高风险区。
3. 再保护 repo-tracked 源码并识别运行产物、临时目录。
4. 最后列验证、剩余风险与清理结果。

## 6. 禁止事项
- 把未验证内容写成已验证。
- 未授权删除源码、测试、协议文件。

## 7. 与其他 skill 的边界
- 不负责生成问题台账，不负责修复执行。
- 本 skill 同时覆盖报告收口与交付面整洁。

## 8. 最小验证/复核要求
- 输出前核对文件清单和验证记录一致。
- 复核交付物仍可定位、关键源码未受影响。
