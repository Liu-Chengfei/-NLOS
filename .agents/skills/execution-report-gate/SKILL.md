# 执行报告 Gate 核验（execution-report-gate）

## 四步闭环流程

查落验报：查 → 落 → 验 → 报。每完成一条必须走完整闭环，禁止跳步。

## §1 八字段格式（唯一逐字载体）

本章节为八字段格式的**唯一逐字权威副本**，所有落实报告书写、核验、审查均以本节为准，不得改写或摘要。

---

# 八字段落实报告格式规范

## 一、字段定义

每条落实报告必须含以下 8 个字段，按顺序书写：

### 字段 1 · 条款号
- 合格：`[40]` 与手册条款编号逐字一致（含方括号）
- 不合格：`41`、`条款41`、`[41条]`、`第41项`

### 字段 2 · 状态
- 合格：`✅`（已落实）或 `❌`（未落实）
- 不合格：空状态、文字"已落实/已完成"

### 字段 3 · 条款（逐字抄录正文全文）
- 合格：全文逐字抄录，含所有分点子项，一字不改
- 不合格：摘要/省略/改写/"见手册第X条"

### 字段 4 · 代码（绝对定位）
- 代码类：`相对仓库根路径::函数名/类名:起止行号`
- 治理类：`载体文件:行号/钩子名`
- 不合格：只写文件名无行号；路径不存在

### 字段 5 · 落实（极尽具体 + 全量映射）
- 条款原文逐句拆 ①②③…，每点写清：该要求 → 落点 → 实现 → 满足
- 必须写到变量名/分支/断言/参数值/返回值/字段级别
- 不合格：空话"已实现"/"按手册执行"；漏点；概述代替全量映射

### 字段 6 · 审查
- 必须写"问题→修复"或"核对范围+核对项"
- 经循环修改的写完整轨迹：违反→改→重映射→不违反
- 不合格：只写"审查通过"/"没问题"

### 字段 7 · 验证
- 可复跑命令 + 具体预期（断言行/输出/数值）
- 不合格：空话"已测试"/"跑通了"

### 字段 8 · 证据
- 真实存在、可直接打开的磁盘路径
- 无独立产物时写明 stdout 落盘位置
- 不合格："见日志"/"已保存"/路径不存在

## 二、一句话模板

```
[N] ✅ | 条款: <逐字抄录> | 代码: <文件::符号:行号> | 落实: ①...②... | 审查: 问题→修复 | 验证: 命令→预期 | 证据: 真实路径
```

## 三、提交前自检清单

- [ ] 字段 3 是否逐字抄录了条款全文，含所有分点子项？
- [ ] 字段 4 是否所有路径真实存在，行号是否与文件实际行号吻合？
- [ ] 字段 5 是否条款原文每一句都有对应落实点？
- [ ] 字段 6 是否写全了"问题→修复"或核对范围？
- [ ] 字段 7 的命令能否原样复跑？
- [ ] 字段 8 的所有路径是否真实存在？

任一为否 → 该条作废重做。

## §2 执行报告 Gate 核验流程

### 核验触发条件

每完成一条条款的八字段落实报告后，运行本 gate 核验：

1. **字段完整性检查**：8 个字段全部存在、顺序正确
2. **状态一致性检查**：✅/❌ 与磁盘锚点状态一致
3. **路径真实性检查**：所有 `代码:` 和 `证据:` 中的路径真实存在
4. **行号准确性检查**：文件存在且行号范围有效
5. **验证命令可复跑检查**：命令可实际执行且输出与预期一致
6. **条款原文逐字抄录检查**：字段 3 与手册条款原文完全一致
7. **全量映射检查**：字段 5 中条款原文每句都有对应落实点
8. **审查完整检查**：字段 6 含"问题→修复"轨迹或核对范围

### 通过 / 不通过判定

| 结果 | 处置 |
|------|------|
| **PASS（全部 8 项通过）** | 该条落实通过，记入 `checklist_gate.md` 勾选 |
| **FAIL（任一项未通过）** | 标注 ❌ → 停工修复 → 重写该条落实报告 → 复验通过后方可继续 |

### checklist_gate.md 勾选格式

按手册条款 [333] 格式，每项通过时逐项勾选：

```markdown
# 执行报告 gate 规则勾选清单（与手册条款编号一一对应）
-1(1)；检查内容：AGENTS.md 存在且五铁律逐字一致
-1(1)；检查内容：pre-commit 钩子存在且断言逐字一致
-1(2)；检查内容：规则清单与手册编号同步（无新增/删除未同步）
-1(2)；检查内容：旧仿真数据集/旧权重/旧结果已清空或归档
-1(2)；检查内容：临时脚本/审计文件/冗余文件已删或入 archive/
……（其余条款按需续列）……
```

## §3 上下文压缩后的重读纪律

`session_start.py` 在每次压缩后强制注入以下指令：

> 上下文压缩后必须重读 `AGENTS.md` + `.agents/skills/execution-report-gate/SKILL.md`（§1 为八字段格式唯一逐字载体）。
> 重读时按 §2 核验流程对最近落实的条款执行 gate 勾选，结果记入 `rules/checklist_gate.md`。

本 SKILL.md 的 §1 是八字段格式的**唯一逐字权威副本**，任何偏离 §1 的解读均以 §1 为准。
