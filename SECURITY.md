# Security Policy

## Supported Scope

Security fixes are accepted for the current active repository state on the default branch.
Historical handoff snapshots under `handoff/` and runtime outputs under `outputs/` are not treated as supported release surfaces.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Use one of these private paths instead:

1. GitHub private security advisory, if this repository is hosted on GitHub with advisories enabled.
2. The maintainer's existing private contact channel used for this repository handoff.

Include:

- affected file paths or entrypoints
- reproduction steps
- impact summary
- whether the issue requires local file access, crafted config input, or untrusted artifact input

The target response is acknowledgement within 5 business days and a status update when triage is complete.
