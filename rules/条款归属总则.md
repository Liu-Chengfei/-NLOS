## 二、执行判据条款处理

含"主线 A/B；第 X 项 怎么查/合格标准/未过处置/验收标准"的条款：
- 第 1 阶段：把判据落为校验脚本/断言
- 判据并入落实报告正文（不单独列出）
- 第 2 阶段执行时逐项对照判定

## 三、第 2 阶段附加义务

冒烟/预达标/全量/验收中发现 bug 或未达标，修复纪律：
1. **归因先行**——第一解释 = 执行偏差（先审执行）
2. **范围限定**——只修本手册 Stage 1-6 映射范围代码
3. **BUG-5 回归链**——每处修复走完整闭环
4. **解冻纪律**——code freeze 后改码必须解冻并记录
5. **禁掩盖**——禁止调 lr 反复试探掩盖 bug
6. **数据/权重纯净性**——改生成器 → 全量重生成 + 重训
7. **留痕**——修复写 decision log + git commit + 报告"审查:"字段
