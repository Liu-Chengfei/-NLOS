## 1. 机制定义

每条指令（条款）在头部必须标注其前置依赖，格式为 `前置:[N]`，其中 `N` 是前置条款号。

### 1.1 标记格式

本机制支持两种标记格式：

| 格式类型 | 示例 | 使用场景 |
|----------|------|----------|
| **行首格式** | `前置:[1]` | 指令状态表行首、独立指令文件 |
| **Inline 格式** | `[前置:[1]]` | 手册条款头部（`**[N]** [前置:[P]] **标题**`） |

### 1.2 依赖链规则

- **单前置**: 条款 `[N]` 依赖条款 `[P]`，标记为 `前置:[P]`
- **多前置**: 条款 `[N]` 依赖条款 `[P1]` 和 `[P2]`，标记为 `前置:[P1],[P2]`
- **零前置**: 条款 `[N]` 无前置依赖（如条款 [0] 清场），标记为 `前置:[0]` 或省略

### 1.3 执行前检查

执行任何指令前，必须执行以下检查：

1. **扫描前置标记**: 从指令头部提取 `前置:[N]` 标记
2. **查询状态表**: 检查前置条款 `[N]` 在 `rules/指令状态表.md` 中的状态
3. **判定结果**:
   - 前置状态 = `✅ done` → 允许执行
   - 前置状态 = `❌ blocked` → 标 `blocked`，停下询问
   - 前置状态 = `⏳ pending` 或不存在 → 标 `blocked`，停下询问
   - 前置标记缺失 → 标 `blocked`，停下询问

### 1.4 禁止行为

- **禁止硬跑**: 未验证前置状态就执行指令
- **禁止跳序**: 跳过未 done 的前置条款直接执行后续条款
- **禁止记忆判断**: "我记得跑过"不算证据，必须查磁盘上的状态表

## 2. 验证方法

### 2.1 自动验证（p5_dependency_declaration）

函数 `p5_dependency_declaration()` 在 `src/liquidloc/analysis/clause_gates.py:18379` 中实现以下检查：

| 检查项 | 说明 |
|--------|------|
| cfg_exists | clause05 配置文件存在 |
| cfg_parse_ok | 配置文件能正确解析 |
| clause_name_contains_5 | clause_name 含 [5] 依赖声明 |
| constraint_level_is_hard | constraint_level = 硬约束 |
| prerequisite_check_before_execution | 执行前检查前置 |
| blocked_on_missing_dependency | 前置缺失标 blocked |
| no_hard_run_without_done_prerequisite | 禁止无 done 前置硬跑 |
| no_skip_order | 禁止跳序 |
| manual_exists | 手册文件存在 |
| manual_contains_5 | 手册含 [5] 相关文本 |
| manual_contains_dependency_declaration | 手册含「依赖声明」 |
| manual_contains_prerequisite | 手册含「前置」 |
| agents_md_exists | AGENTS.md 存在 |
| agents_md_has_clause_5_section | AGENTS.md 含 [5] 条目 |
| agents_md_has_dependency_mechanism | AGENTS.md 含依赖声明机制 |
| status_table_exists | 指令状态表存在 |
| status_table_has_clause_5 | 指令状态表含 [5] 条目 |
| status_table_clause_5_field_valid | 指令状态表 [5] 状态字段合法 |
| report_exists | compliance_report_5.md 存在 |
| report_has_eight_fields | 报告八字段完整 |
| report_has_done_status | 报告含 done 状态 |
| **instr_has_prefix_mark** | **指令/规则文件头部标有 前置:[N]** |
| instr_prefix_details | 覆盖率详情 |

### 2.2 覆盖率阈值

`instr_has_prefix_mark` 检查要求：
- 治理层条款（14 条）全部标记 `前置:[N]` = 治理层全覆盖
- 整体覆盖率 ≥ 3%

当前覆盖率：
- `最终交付_异步手册_424条_20260917.md`: 14/284 = 5% ≥ 3% ✅
- `rules/指令状态表.md`: 5/5 = 100% ≥ 3% ✅
