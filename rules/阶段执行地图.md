# 阶段执行地图（唯一执行顺序，禁止跳 Stage）

## 执行顺序硬约束

指令按 Stage 排队，**禁止跳 Stage**。每批全部 done + verify_slam 通过，才发下一批。任一 gate 未过不进入下一阶段。

## 出口 gate 说明

每个 Stage 的出口 gate 条件：
1. **落实报告核验 PASS**：所有条款的八字段报告无缺失字段、无空话、无虚假路径
2. **判据全过**：执行判据条款对应的校验脚本/断言全部通过
3. **verify_slam 通过**：综合核验脚本全部通过

任一条件未满足 = 不进入下一阶段。
