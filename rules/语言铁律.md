# 语言铁律（GLM 5.3 专属·硬约束）

## 核心判据

全程使用**简体中文**回答、解释、汇报与书写落实报告；禁止英文回答、禁止中英混杂。

## 适用范围（一律简体中文）

- 代码注释
- 日志输出
- 提交信息
- 命名说明
- 验证输出解读
- 批处理小结
- 阶段验收报告
- 交付说明

## 允许例外（可保留英文原样）

- 专有名词
- API 名
- 变量名
- 单位符号
- 期刊名
- 引文原样

## 违规处置

- 违反 = 该条未落实
- 一份落实报告出现 **3 处及以上**非简体中文表述（代码/日志/引文原样除外）= 该份落实报告**作废重做**
