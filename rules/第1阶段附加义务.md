# 条款[16]：第1阶段附加义务（治理层）

## 核心判据
- 落实中发现任何 bug → 顺手修根因（禁止留 TODO/绕开/注释掉旧实现）
- bug 检查范围 = 本手册 Stage 1-6 条款映射到的代码（正在落实的条款 + 已落实条款 + 其依赖的同体系模块）
- 不扩大到条款映射范围之外（范围外发现 bug 只记录上报 decision log 告知用户，不擅自修改）
- 每条条款落实完成时对条款映射范围代码做一次 bug 检查（静态审查/运行断言/单测至少一种）
- 发现即修根因
- 修复与检查结果写入该条落实报告"审查:"字段并留痕（git commit + decision log）

## 禁止项
- 禁止留 TODO
